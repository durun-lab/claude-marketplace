# RFC 0206 layer-time-ops: レイヤーを前後に動かす `shiftLayer` と、有効を切り替える `setLayerEnabled`

状態: 提案

## 変える理由

Timeline の帯の中のドラッグでレイヤーをコンポジションの時間軸で動かす操作と、レイヤーの見出しの有効のボタンでレイヤーを描くかを切り替える操作が `mm-ops` に無い（[18-ui-clarity.md](../design/18-ui-clarity.md) の B1）。画面の部品（T3 の見出しのボタン、Z4 の Selection のドラッグ）はこの操作を使う。

## 先行事例

| 先行事例 | 採ったもの |
|---|---|
| After Effects でレイヤーの帯をドラッグすると、レイヤーのキーフレームも一緒に動く | `start` と、コンポジションの時刻で評価するキーフレームを同じだけ動かす。イン点とアウト点は変えない |
| After Effects はレイヤーを 0 より前にも置ける（帯がコンポジションの先頭より左に出る）。Premiere Pro と DaVinci Resolve はクリップをタイムラインの先頭より前へ動かせない | 操作は 0 より前の始まりも受ける（データの形と `trimLayer` に合わせる）。0 で止めるかは Z4 のドラッグが決める |
| Final Cut Pro の接続クリップは、動かすか外すまで接続先に付いたまま。ドラッグすると、動かした先の基本ストーリーラインのクリップに付き直す | 接続（`attach_to`）は変えない。付け直しは残す |
| After Effects の Video のスイッチ（目のアイコン）と Premiere Pro の Toggle Track Output。After Effects はトラックマットに使うレイヤーの映像を切っても、マットとして効く | レイヤーごとの有効の切り替え。今の `Layer::enabled`（描かず鳴らさない。トラックマットに使うレイヤーは無効でも効く）をそのまま使う |
| 社内の `lockLayer` | 前の値を置く同じ操作を逆操作にし、`touches` はレイヤーだけ |

## 新しく決めたこと

- `shiftLayer { layer, by }`: `by` はコンポジションの時間軸。`start` と、コンポジションの時刻で評価するキーフレーム（不透明度、変形、切り抜き、マスク、音量とパン、効果とノードのパラメータ、字幕の置き場所）を `by` だけ動かす。`mm-render` はこれらを `CompCx::t` で評価するので、キーフレームを動かさないと、レイヤーの中身に対してアニメーションの時刻がずれる。
  - 変えないもの: イン点とアウト点、素材の時刻の再フレーミング（被写体の位置は素材の時刻で決まる）、レイヤーの始まりからの時刻のタイムリマップ。入れ子のコンポジションと sequence の中、コンポジションのマーカーと長さも変えない（After Effects でも、レイヤーを動かしたときにコンポジションのマーカーと長さは変わらない）。音のフェードはレイヤーの端からの長さなので、レイヤーと一緒に動く。
  - ノードの種類が自分で読む時刻: `lottie` と `web.cef` はレイヤーの写像を通した時刻（`FrameCx::source_time`）を読むので、アニメーションもレイヤーと一緒に動く。`shader.wgsl` と `shader.hlsl` の `u.time` はコンポジションの時刻なので動かない（After Effects のエクスプレッションの `time` もコンポジションの時刻）。
  - 始まりが 0 より前になる動かし方も受ける。データの形は負の `start` を許し、`trimLayer` もイン点を前へ動かすと 0 より前の始まりを作る。拒否すると、0 より前から 0 以降へ動かした操作の逆操作が通らない（取り消しが `Couldn't undo` になる）。0 より前の部分は描かない。
  - 時刻の桁あふれは拒否する。途中まで書き換えたプロジェクトのデータは `Op::apply` が元に戻す。
  - 接続（`attach_to`）は変えず、接続先のカットとの位置の差が `by` だけ変わる。接続を外すと逆操作が `attachLayer` との 2 つの操作になり、拒否すると接続のあるレイヤーを Selection でドラッグできなくなるので、どちらも採らない。
  - 逆操作は `-by` の `shiftLayer`。`touches` はそのレイヤー（ほかの所を読まない）。ロックしたレイヤーは、ほかの操作と同じロックの検査で Claude の操作経路から拒否する（`OpError::Locked`）。
- `setLayerEnabled { layer, enabled }`: データの形は今の `Layer::enabled`（既定は有効）のまま。無効のレイヤーは描かず、鳴らさず、字幕の元にもならない。逆操作は前の値を置く同じ操作、`touches` はそのレイヤー。

## インターフェースの変更

`mm-ops`（基礎の層。API クレートではない）に操作を 2 つ足す。生成物（`schema/ops.json`、`ui/sdk/src/generated/ops.ts`）が増える。データの形と `sidecar.schema.json` は変わらない。既存の操作は変えない。

## 試験

- `crates/mm-ops/tests/it/layer_time.rs`: レイヤーの全部のパラメータに JSON をたどってキーフレームを置き、`shiftLayer` がコンポジションの時刻のものを全部動かし、イン点とアウト点、再フレーミング、タイムリマップを変えない。始まりが 0 より前になる動かし方と、`trimLayer` で 0 より前から始まるレイヤーを動かしたときの逆操作。時刻の桁あふれの拒否。ロック、有効の切り替え、無いレイヤー。
- 性質テスト（`spec/layer_time.rs`）: 操作の種の組 `Time` を足す。重みは 1 にし、ほかの組の重みを 2 倍にする（時間の操作が入れ子のレイヤーを動かすと、unprecompose が通りにくくなるため）。生成器が全部の操作を通すかの試験は、全部が通った所で打ち切る（上限は 20000 回）。

## 残したこと

- Final Cut Pro のように、動かした先のカットに接続を付け直すこと。今は接続がカットのリップルに追従していない（`attach_to` を読むのは検証と `touches` だけ）。追従を作る PR が、ドラッグのトランザクションに `attachLayer` を足すかを決める。
- `mm log` と `mm diff` の文（`apps/mm/src/describe.rs`）には 2 つの操作の分を足さない。名前とフィールドの文で出る（`trimLayer`、`attachLayer` と同じ）。

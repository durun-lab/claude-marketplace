## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| ポインターの下 | ポインターが乗っている部品。Timeline の当たった所、ツールバーの部品、再生の操作のバーの部品を 1 つの型にまとめ、レイヤーとカットの添字も持つ。カーソル、ステータスバー、ツールチップが同じ値を引く。右クリックのメニューの種類は `Under::hit_kind`（`HitKind::of`）で引く | `Pointee`、`Under` |
| ポインターの下の手がかり | ポインターの下と、ツールチップの中身、ポインターの位置の組。描画のスレッドが作り、UI のスレッドが 1 つの関数（`HintSlot::current`）で引く | `Hint`、`HintSlot`、`Ui::hint` |
| ステータスバー | Timeline の下端の 1 行。左にポインターの下でできること（ドラッグ中は動かした量と吸い付いた先）、右に Snapping の入/切と今のツールを出す。WebView の下端のステータスの行とは別 | `TimelineLayout::status`、`STATUS_H`、`status_left`、`status_right` |
| ツールチップの中身 | サーフェスの部品のツールチップに出すもの。コマンドの表の行（名前、キー、説明）か、表に無い部品の文（帯の種類、名前、範囲、長さ）。同じ値の間は同じ対象とみなし、変わったら文と位置を差し替える | `TooltipContent`、`tooltip_of`、`bar_tooltip` |
| ツールチップを出す時機 | 部品の上で止まって出し、出ている間に別の部品へ移れば短い待ちで差し替え、一定の時間で消す。待ち時間は Windows の標準のツールチップの値 | `Dwell`、`Delays`、`TooltipAction` |
| カーソルの形 | ポインターの下と修飾キーで決めるカーソル。仕切りの上と仕切りをつかんでいる間は仕切りの形を先にする。左右と上下の矢印と禁止は Windows の標準、roll、slip、slide、刃は自前の画像 | `CursorKind`、`cursor_for`、`splitter_cursor` |

## 置き換えた語

### UI の分かりやすさ（Z5、カーソル、ツールチップ、ステータスバー）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 入口（手がかりの） | UI のスレッドがポインターの下の手がかりを引く `HintSlot::current`。入口は段階 2 と 3 で置き換えた語 | 置き場所（`HintSlot`）、1 つの関数（`HintSlot::current`） |
| 窓（slip のカーソルの / ツールチップの） | slip のカーソルが表すカットの枠 / ツールチップの Win32 のウィンドウ。用語集で窓は区間とブロックに置き換えた語 | カットの枠 / ウィンドウ |
| 絵（自前のカーソルの） | `cursor/art.rs` がコードで描くカーソルの画像。用語集で絵は画像に置き換えた語 | 画像 |
| 被り | 縁を含めて形が画素を覆う割合（アルファ） | 覆う割合 |
| 鳴る（タイマーが） | `SetTimer` で掛けたタイマーの時間が来て `WM_TIMER` が届くこと | 時間が来る |
| 逃がす（ツールチップを上へ） | 下に入らないツールチップを、ポインターの上に出すこと | 上に出す |
| 覚える（ポインターの位置を） | `Ui::note_pointer` が最後のポインターの位置を置き直すこと。覚えるは段階 3 でキャッシュするに置き換えた語 | 置き直す |
| 印（Alt の lParam の / 列挙の） | lParam のビット / 見つけたことを示す変数。用語集で印はフラグとマーカーに置き換えた語 | ビット / フラグ |
| 試験（ツールチップのテストの HWND） | 単体テストで作る親と子の HWND。用語集で試験はテストに置き換えた語 | テスト |
| 写らない（PrintWindow に） | PrintWindow のスクリーンショットに出ないこと。写すはコピーの意味で置き換えた語 | スクリーンショットに出ない |
| `Cmd`（ツールチップを出す時機の） | 状態機械が UI のスレッドに頼むこと（出す、隠す、タイマーを掛ける・止める）。コマンドの表のコマンドと紛れる | `TooltipAction` |
| `quiet`（`Dwell` の） | 押下、ホイール、autopop で隠したこと。何が静かなのかが名前に無い | `dismissed` |
| `SS` | 1 画素の縦横のサンプル数。略だけでは何の数か分からない | `SUPERSAMPLE` |

## 時間とシーケンス

| 用語 | 定義 | 識別子 |
|---|---|---|
| トランジション | カットの頭（前のカットとの境）に置き、境を中心に前後へ半分ずつ掛かる切り替えの絵。種類はノードで、長さを持つ | `Transition`、`Cut.transition_in`、`setTransition` |
| 進み具合（トランジションの） | トランジションの中の位置。0 は前のカットそのもの、1 は次のカットそのもの | `u.progress` |
| 巻き戻し | 出ていくカットを逆向きに早回しで描くトランジション。逆再生の倍率を持つ | `rewind.wgsl`、`TRANSITION_REWIND_PARAM`、マクロ `rewind` |

## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| 共通のコード（トランジションの） | パックの全部のトランジションの前に付ける WGSL。マット、重ねる絵、映像の動きを 1 つのシェーダーで合成する | `transitions/_prelude.wgsl`、`Transitions` |
| マット | トランジションで次の場面を見せる所（1 = 次の場面、0 = 前の場面） | `fn matte` |
| 重ねる絵 | トランジションで前と次の場面の上に描く絵（乗算済みアルファ） | `fn overlay` |
| シャッター | 重ねる絵とマットのモーションブラーで、1 コマのうち時刻をずらして平均する長さ（コマの割合）。境の両端では閉じる | `SHUTTER` |
| 乱数の種（トランジションの） | 光の筋やブロックの並びを決める数。`transition.wgsl` の `p0` | マクロ `transition` の `seed` |
| ページの約束 | web の部品のページが守る書き方。`mmSetTime(t, data)` の `t` と `data` だけで画面を作り、時計、乱数、タイマー、CSS と SVG と Web Animations の動き、外の資源を使わない | `mm_pack::page::check_page` |
| 動く部品 | 時刻で中身が変わるか、出た後も動き続ける web の部品。毎フレーム描く | web 手順の `animated: true` |
| 札（web の部品の） | 部品の中の、角丸の地に短い文字を置いた印（肩書き、ToDo の今の行、注記）。文字のスタイルのプレートとは別 | `marks` の `kind=tag`、`cta` の `kind=tag` |
| マークアップ（geneva の） | geneva のタイムラインの `html` の source。画面の大きさの箱なら `web.cef` のレイヤーにする | `geneva_cmd::html` |
| 重ね絵（geneva の） | geneva が PNG の連番に焼いた吹き出しや札。PNG のまま取り込む | `assets.*` の PNG |

## 書き出しと納品

| 用語 | 定義 | 識別子 |
|---|---|---|
| 確認用の書き出し | geneva の `outputs` の映像の出力。本編と同じコンポジションを縮めて書くレンダーターゲットにする | `outputs.draft`、`geneva_cmd::target::extra_targets`、`mm render --target draft` |
| 区間（再現の） | 再現のテストで書き出して前の書き出しと比べる、4 秒の時間の範囲。始まりは 0.1 秒の格子にそろえる | `replay::window`、`WINDOWS` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| カットの帯 | Transition パネルで、sequence のカットを長さに比例した幅で並べた列。境のトランジションをカットの頭の印と名前で出す | `Strip`、`.mm-tr-strip` |
| マスクの区画 | Inspector で、マスク 1 つの位置、大きさ、半径の入力欄と削除のボタンをまとめた区画。区画は最後に並び、追加のボタンが続く | `maskSection`、`Section.maskId` |

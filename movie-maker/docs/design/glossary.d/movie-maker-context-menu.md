## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 右クリックのメニュー | サーフェスの右クリックかメニューキーで、当たった所に合わせて出すネイティブのポップアップのメニュー。項目と並びはメニューバーと同じ形（コマンドの表と `menu.rs` の並び）で、選んだ項目はメニューバーと同じ `on_menu_event` で実行する | `context_menu.rs`、`menu::context_groups`、`Forward::ContextMenu` |
| 当たった所 | ポインターの下の所を粗く分けたもの（カット、レイヤーの帯、見出し、目盛り、空き）。右クリックのメニューの種類を選ぶ。描画スレッドの当たり判定（`Hit`）から作る | `mm_ui_layout::Place`、`Place::of` |
| メニューキー | 右クリックのメニューを開くキー（Shift+F10 とアプリケーションキー）。OS が `WM_CONTEXTMENU`（lParam は -1）を送り、選んでいるものの位置でメニューを出す | `WM_CONTEXTMENU`、`PointerEvent::ContextMenuKey` |
| 右クリックの時刻 | 右クリックした点の時刻。Blade と同じく、フレームにそろえ、Snapping が入なら再生位置に吸い付ける。Split Clip Here の割る時刻で、次の左クリックまで持つ | `Action::ContextMenu::time`、`ContextSlot::time` |

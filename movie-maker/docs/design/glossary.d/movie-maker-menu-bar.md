## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| メニューバー | ウィンドウの上端の File、Edit、View、Playback、Timeline、Help。Tauri のメニュー（muda）で出し、項目の名前、キーの見た目、押せるかは UI のコマンドの表から作る。項目の無いメニューは出さない | `menu.rs`、`menu::build`、`menu::shown` |
| メニューの並び | メニューごとのコマンドの ID の並び。区切り線で分けたグループの並びとして持ち、表に無い ID はスキップする。右クリックのメニューも同じ形 | `menu::BAR`、`menu::Groups` |
| グループ（メニューの） | メニューの並びの中の、区切り線で分けた項目のまとまり。空のグループは区切り線ごと消える | `menu::lines` |
| 区切り線（メニューの） | メニューの中で、グループの間に引く横線 | `menu::Line::Separator` |
| アクセスキー | メニューの名前の下線の字（`&File` の F）。Alt と一緒に押すか、F10 でメニューモードに入った後に押すと、そのメニューを開く。WebView2 は Alt+英字をウィンドウに渡さないので、WebView で押した表に無い Alt+英字は、ウィンドウのフックがウィンドウに渡して開く | `Menu::title`、`Forward::MenuKey` |
| メニューモード | キーでメニューバーとメニューの項目を選ぶ状態。F10 かアクセスキーで入り、Esc で出る。サーフェスでは、Alt だけを押して離しても入らない | `SC_KEYMENU` |
| 既定のウィンドウプロシージャ | アプリが処理しないウィンドウのメッセージを、Windows の既定の動き（Alt+F4 で閉じる、F10 でメニューモードに入るなど）で処理する関数 | `DefWindowProcW` |
| ウィンドウのコマンド（UI の） | Tauri のウィンドウが実行する UI のコマンド。Exit（閉じるボタンと同じく閉じる）と About | `commands::WindowAction`、`Action::Window` |
| ウィンドウのフック | パネルとウィンドウのコマンドと、WebView で押したアクセスキーを、Tauri の `AppHandle` と `Window` で実行する関数。メニューバーと一緒に、ウィンドウを作るときに設定する | `commands::WindowHook`、`commands::Forward` |
| パネルのコマンドのイベント | パネルが持ち主のコマンドを、メニューとキーから Shell に実行させる Tauri のイベント。中身はコマンドの ID | `mm:panel-command`、`PANEL_COMMAND_EVENT`、`CommandsApi.onPanelCommand` |

## 置き換えた語

### メニューバー（D1）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 区切り | メニューのグループの間の線（パスの区切り文字、回の区切りと紛れる） | 区切り線 |
| 行（メニューの） | メニューの項目か区切り線の 1 つ（`Line`。コマンドの表の行と紛れる） | 項目、区切り線 |
| 飛ばす | メニューの並びで表に無い ID を出さないこと | スキップする |
| 置く、置き直す | 押せるかとチェックの状態をメニューの項目へ / ウィンドウのフックの渡す先 | 反映する / 設定する |
| 出さない一覧、出さないもの | メニューに出さないコマンドの一覧 | `NOT_IN_MENUS` |
| 頭の字 | メニューの名前でアクセスキーにする字 | 先頭の字 |
| メニューバーに入る、メニューバーの出入り | F10 や Alt で、キーでメニューを選ぶ状態に入ること | メニューモードに入る、メニューモードの出入り |
| 決まりのキー | F10 | 標準のキー |
| 既定の処理 | キーのメッセージを `DefWindowProcW` に渡すこと | 既定のウィンドウプロシージャ |
| 枠の側（ウィンドウの） | メニューバーとタイトルバーのある所 | 非クライアント領域 |
| Tauri の側 | ウィンドウのコマンドを実行する所 / パネルとウィンドウのコマンドの渡し先 | Tauri のウィンドウ / ウィンドウのフック |
| Rust の側 | パネルのコマンドをメニューとキーから呼ぶ所 | アプリの呼び出し箇所 |
| 知らせる（パネルに） | Shell が持ち主のパネルの `requests` を 1 つ進めること | `requests` を進める |

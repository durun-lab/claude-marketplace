## モバイル版の通しの確認

| 用語 | 定義 | 識別子 |
|---|---|---|
| モバイル版の通しの確認 | 実際の `mm-serve` の人の待ち受けと Claude の待ち受けを相手に、Playwright の iPhone と Android の端末の設定で、登録からコメント、提案の承認、Story、送信待ちのキューまでを順に通すテスト | `ui/mobile/e2e/` |
| PC の側（通しの確認の） | デスクトップのアプリを起動せず、フィクスチャから Claude の待ち受けと人の待ち受けを始める実行ファイル。標準入力で登録コードを出す | `mobile_rig` |
| 中継（通しの確認の） | `tailscale serve` の代わり。自己署名の HTTPS で受け、`Host` と `Tailscale-User-Login` を付け替えて人の待ち受けへ流す | `startRelay` |
| 資格を使っていない登録 | 登録の応答の後に、端末の資格の付いた要求がまだ 1 回も通っていない登録。名前を塞がず、登録コードの期限を過ぎると端末の一覧から消える | `unused`、`pairing_not_kept` |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 文字の下の矩形 | Timeline の矩形のうち、文字の下に描くもの。帯までの数の後ろに、テクスチャで描くサムネイルを差し込む。帯に描くものの入力は `PaintInput` のフィールドで足し、関数を増やさない | `PaintInput::under_text`、`UnderText` |
| 受け渡しの状態（描画スレッドの） | 描画スレッドが共有状態から `Ui` へ渡すものごとの、最後に渡した状態のまとまり。`Ui` を作り直したら一緒に作り直す | `Syncs` |
| 取り込みの通し番号 | 素材の取り込みを終えるたびに進む数。描画スレッドが、読めなかったサムネイルを読み直す合図にする。取り込み済みの素材を取り込み直したときはプロジェクトのデータが変わらないので、`doc_serial` と別に持つ | `Shared::ingest_serial` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| サムネイル（帯の） | Medium と Large の行の帯（シーケンスはカット）の左に出す、素材の 1 コマ。キャッシュの `thumbs/` の JPEG（Media のパネルと同じ）から作る。名前はその右から始める | `mm-ui-layout` の `thumbs.rs`、`timeline_thumbs`、`ThumbQuad` |
| キー（サムネイルの） | サムネイルを引く、素材のコンテンツハッシュ（キャッシュの `thumbs/` のフォルダー名）。撮影素材と静止画のレイヤーとカットだけが持つ | `Item::thumb`、`CutBar::thumb` |
| 外したキー（サムネイルの） | 読めなかった（音だけの素材、キャッシュの無い素材）ので帯から外したキー。名前を左に戻し、編集でモデルが置き換わっても外したままにして、素材の取り込みを終えたら帯に戻す | `DroppedThumbs`、`Ui::retry_thumbs`、`ThumbStats::dropped` |
| アトラス（サムネイルの） | 帯のサムネイルを 1 枚のテクスチャにまとめたもの。見えている全部を 1 回の描画呼び出しで描く。いっぱいになったら、直近のフレームで描かなかったものから捨てる。デバイスの資源なので、サーフェスの作り直し（`Lost`）では捨てない | `mm-ui-wgpu` の `thumbs.rs`、`ThumbRenderer` |
| スロット（アトラスの） | アトラスを格子に分けた 1 つの枠（192x108 物理ピクセルを 200 個）。サムネイル 1 枚が入る | `Slots`、`SLOT_W`、`SLOT_H` |
| スロットの画像 | スロットに入れる RGBA8。JPEG を 16:9 の中央で切り出してスロットの大きさに縮めた画像に、ミップレベルを続けたもの。アプリの読み込みのスレッドが作る | `slot_image_from_rgb`、`slot_image_len` |
| ミップレベル（アトラスの） | スロットの画像を縦横半分ずつにした縮小の画像（96x54 と 48x27）。帯を縮めて描くときに GPU がここから引き、間引いた画素がスクロールでちらつかない | `MIPS`、`level_range` |

## 置き換えた語

### UI の分かりやすさ（T5、帯のサムネイル）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 画 | 帯の先頭の 1 枚。用語集で画はサムネイルに置き換えた語 | サムネイル |
| 鍵 | サムネイルを引く素材のコンテンツハッシュ。用語集で鍵はキーに置き換えた語 | キー（サムネイルの） |
| 入点 | レイヤーとカットの始まり | イン点 |
| セル、`CELL_W`、`CELL_H`、`cell_from_rgb`、`cell_len`、`cell_origin`、`cell`（引数と変数） | アトラスの 1 つの枠と、そこに入れる画像。スロットと同じものを 2 つの語で呼んでいた | スロット、スロットの画像（`SLOT_W`、`SLOT_H`、`slot_image_from_rgb`、`slot_image_len`、`slot_origin`、`image`） |
| 区切り（アトラスの 1 区切り） | スロットの定義。区切りは区切り線と紛れる | 格子に分けた 1 つの枠 |
| 印（使った印、読めなかった印） | スロットの状態。用語集で印はマーカーとフラグに置き換えた語 | 最後に描いたフレームを記録する、読めなかったと記録する |
| 口（受け渡しの口、結果を受ける口） | `Ui` のサムネイルの関数と、読み込みのスレッドの結果を受ける所。用語集で口はインターフェースや呼び出し箇所に置き換えた語 | 頼む関数と受ける関数、結果の受け手（`Receiver`） |
| 名前の部分（帯の） | 帯の名前を置く矩形 | 名前を置く所（帯の） |
| `timeline_quads_split`、`into_quads_split` | 文字の下の矩形と帯までの数を返す関数。何で分けるのかが名前に無く、波形の入力を足す関数と並ぶと同じ役目の関数が増える | `PaintInput::under_text`、`UnderText::bars` |
| `Counts::below` | 帯までの矩形の数。文字の下の矩形の数（`under`）と同じ意味に読める | `Counts::bars` |
| `Slots::look` | 描くサムネイルのスロットを引き、無ければ読み込みを頼む。何をするかが名前に無い | `Slots::slot_to_draw` |
| `cut_range`、範囲（帯の矩形の） | カットの見えている矩形。範囲は時間の範囲と紛れる | `cut_rect`、矩形 |
| 縮小の段 | アトラスの縮小の画像。用語集で段は行や工程に置き換えた語 | ミップレベル |

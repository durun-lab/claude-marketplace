## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 帯の波形 | 音のある撮影素材のレイヤーとカットの帯に出す、縦の矩形の並び。Medium の行は帯の下端のマーカーの高さ、Large の行は帯の下半分に出し、Small の行は出さない。名前は帯の上の部分、キーフレームのマーカーは波形の上に重ねる。キャッシュに波形がまだ無い素材は出さない | `paint/wave.rs`、`wave::region`、`Depth::Wave` |
| 波形の元 | 帯の波形を引く素材の ID と、コンポジションの時刻から素材の時刻への換算（`at` に `src`、`speed`）。レイヤーは `in` と `speed`、カットはカットの `in` にカットの速さとレイヤーの速さを掛ける。タイムリマップのあるレイヤーは持たない | `WaveSource`、`Item::wave`、`CutBar::wave` |
| ピークの段 | 波形のピークを 2 個ずつの最大で重ねた粗さの段。ズームで 1 列が受け持つ素材の時間に合う段から最大を引き、縮小しても大きな音を落とさない。素材ごとに読み込みの 1 回だけ作る | `Peaks`、`Peaks::max_in` |
| 波形の列 | 波形の矩形 1 本分の幅（2 論理ピクセル）。同じ高さの列が続けば 1 つの矩形にまとめる | `paint/wave.rs` の `COLUMN_PX` |
| 波形の使い回し | 倍率、左端の時刻、縦のスクロール、行の領域、ドラッグ中の見た目が前の周と同じなら、前に作った波形の矩形をそのまま使うこと。モデルや行の高さが変われば捨てる | `Waves::quads`、`Waves::invalidate` |
| 波形の読み込み | キャッシュの波形（`cache/audio/<ハッシュ>/waveform.json`）を専用のスレッドで読み、読めた素材から Timeline に渡す。無い素材は 2 秒ごとに探し直す | `WaveSync` |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| デバイスを作る枠（GPU の） | GPU のデバイスを作る間だけプロセスが持つ、PC 全体で 4 つの名前付きミューテックスの 1 つ。並べて回すテストが同時にデバイスを作って `Not enough memory left` で失敗しないよう、同時に作る数を絞る。持ち主のプロセスがクラッシュしても OS が放す | `mm_gpu::device_slot`、`DeviceSlot`、`GpuContext::with` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 帯の波形 | 音のある撮影素材のレイヤーとカットの帯に出す、縦の矩形の並び。Medium の行は帯の下端のマーカーの高さ、Large の行は帯の下半分に出し、Small の行は出さない。名前は帯の上の部分、キーフレームのマーカーは波形の上に重ねる。キャッシュに波形がまだ無い素材は出さない | `paint/wave.rs`、`wave::wave_area`、`Depth::Wave` |
| 波形の元 | 帯の波形を引く素材のコンテンツハッシュと、コンポジションの時刻から波形の時刻への換算（`comp_time` に `wave_time` が当たり、`speed` 倍で進む）。レイヤーは `start` に `in`、カットはカットの始まりにカットの `in` が当たり、カットの速さにレイヤーの速さを掛ける。タイムリマップのあるレイヤーは持たない | `WaveSource`、`Item::wave`、`CutBar::wave`、`WaveResolver` |
| 波形の時刻 | キャッシュの波形のピークを引く時刻。音の最初のサンプルから数える秒で、素材の時刻（映像の先頭から）に音と映像の先頭のずれ（`timebase_offset`）を足したもの | `WaveSource::wave_time`、`wave_time_at` |
| 見た目の振幅 | 波形の列の高さの、波形の領域に対する割合（0..=1）。ピークの平方根で、話し声の小さな音も見えるよう持ち上げる。1 バイト（`FULL_SCALE` が 1）で持つ | `Peaks::max_in`、`wave.rs` の `display_byte` |
| ピークの階層 | 見た目の振幅を 2 個ずつの最大で重ねた、粗さの違う並び。ズームで 1 列が受け持つ時間に合う階層から最大を引き、縮小しても大きな音を取りこぼさない。素材ごとに読み込みの 1 回だけ作り、全部の階層で元のピーク 1 個に約 2 バイト | `Peaks` |
| 波形の列 / 列の並び | 波形の矩形 1 本分の幅（2 論理ピクセル）。同じ高さの列が続けば 1 つの矩形にまとめる / 帯の見える範囲を覆う列。列の境は時刻 0 から列の幅ごとに固定し、横に動かしても同じ列が同じ時間を受け持つ | `paint/wave.rs` の `COLUMN_PX` / `wave::Columns` |
| 波形の使い回し | 倍率、左端の時刻、縦のスクロール、行の領域、ドラッグ中の見た目（使い回しのキー）が前の周と同じなら、前に作った波形の矩形をそのまま使うこと。モデル、行の高さ、ピークが変われば捨てる | `ReuseKey`、`Waves::reuse_or_build`、`Waves::invalidate` |
| 波形の読み込み | キャッシュの波形（`cache/audio/<コンテンツハッシュ>/waveform.json`）を専用のスレッドで読み、読めた素材から Timeline に渡す。無い素材は、素材の一覧が変わったときと、取り込みが素材の出力を作り終えたときに探し直す | `WaveSync`、`WaveWanted` |
| 取り込みの通し番号 | アプリの取り込みが素材 1 つの出力（プレビュー動画、サムネイル、波形）をキャッシュに作り終えるたびに進む数。プロジェクトにすでにある素材はキャッシュだけを作り直して素材の一覧が変わらないので、波形の読み込みはこれでも探し直す | `Shared::ingest_serial` |

## 置き換えた語

### UI の分かりやすさ（帯の波形）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| `WaveSource::at`、`src`、`src_at` | 波形の元の、コンポジションの時刻と、そこに当たる波形の時刻。`src` は素材（source）とも読め、素材の時刻か波形の時刻かが分からない | `comp_time`、`wave_time`、`wave_time_at`（波形の時刻） |
| `WaveKey`、`Waves::memo`、`Waves::quads` | 前に作った波形の矩形を使い回すかを決める入力、前に作った矩形、使い回すか作り直すかの関数。何のキーか、何を返すかが名前に無い | 使い回しのキー（`ReuseKey`）、`Waves::last_built`、`Waves::reuse_or_build` |
| `wave::region` | 帯の中の波形の領域。サーフェスの領域（`mm_ui_wgpu::Region`）と紛れる | `wave::wave_area` |
| `Grid`、`columns`（描く関数） | 帯の見える範囲を覆う波形の列の並び / 1 つの波形の元の矩形を足す関数。`Grid` はスナップの格子と紛れ、`columns` は列の並びと同じ名前 | 列の並び（`Columns`）/ `push_wave` |
| `FULL`、`shown` | 見た目の振幅の 1 に当たる 1 バイトの値と、ピークをその 1 バイトにする関数。何が満ちるのか、何を見せるのかが分からない | `FULL_SCALE`（フルスケール）、`display_byte` |
| `DISABLED_SCALE` | 無効なレイヤーの波形の不透明度に掛ける倍率。大きさの倍率と紛れる | `DISABLED_ALPHA_FACTOR` |
| `WaveRefs` | レイヤーとカットから波形の元を引くもの。何への参照かが分からない | `WaveResolver` |
| 段（ピークの） | 見た目の振幅を 2 個ずつの最大で重ねた並び。用語集の「段」（工程、ステップ）と紛れる | 階層（ピークの階層） |
| 版（素材の一覧の）、`rev`、`wave_rev` | 素材の一覧を作り直すたびに進む数 | 通し番号（`serial`、`wave_serial`。`doc_serial` と同じ） |
| `round` | 波形のキャッシュを探した回数。試合の回と紛れる | `scans`、`Job::scan` |
| 鍵（使い回しの） | 前に作った波形の矩形を使い回すかを決める入力 | キー（使い回しのキー） |
| 落ちる、落とす | デバイスの作成の失敗 / プロセスの異常終了 / 枠の破棄 / 縮小で大きな音を見せないこと | 失敗する / クラッシュする / 破棄する / 取りこぼす |
| 書きかけ | 付属ファイルを書いている途中の内容 | 書いている途中の内容 |
| 写像（時刻の） | コンポジションの時刻から波形の時刻へ | 換算 |
| 札 | GPU のデバイスを作る間だけ持つ、名前付きのミューテックス | デバイスを作る枠（`DeviceSlot`） |
| 入口の関数（描く） | `timeline_quads` と `timeline_overlay`。用語集の「入口」（HTTP のエンドポイントなど）と紛れる | 公開する関数 |

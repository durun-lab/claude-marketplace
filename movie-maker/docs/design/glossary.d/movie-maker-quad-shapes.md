## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 形（Quad の） | Quad を塗る図形の種類。矩形（既定）、ひし形、上下左右の向きの二等辺三角形。どれも外接する矩形に収まり、矩形のほかは縁にアンチエイリアスを掛ける | `QuadShape`、`Quad::shape`、`Quad::shaped` |
| 外接する矩形（Quad の） | 形がちょうど収まる矩形。Quad の位置と大きさはこれで持つ | `Quad::rect` |
| アンチエイリアス（Quad の形の） | 縁までの符号つき距離（外が正、物理ピクセル）から被覆率を「0.5 - 距離」で出し、縁の画素を背景と混ぜること。縁の幅は表示の倍率に依らず 1 物理ピクセル。矩形には掛けず、辺は画素の中心の判定で切る | `quads.rs` の `edge_distance`、`fs` |

## 置き換えた語

### UI の分かりやすさ（Quad の形）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| `Shape`（mm-ui-layout） | Quad の形の型。同じクレートの `DrawingShape` と、mm-store の `Shape`（描き込みの形）と紛れる | `QuadShape` |
| 頂点が上 / 下 / 左 / 右（の三角形）、頂点の向き | 三角形のとがった側の方向。同じファイルの GPU の頂点（頂点バッファ、頂点のシェーダー）と紛れる | 上向き / 下向き / 左向き / 右向き、三角形の向き |
| 矩形（外接する矩形の意味で）、外接矩形 | 形の説明の中の矩形。形の 1 つの矩形（`QuadShape::Rect`）と紛れる | 外接する矩形 |
| なめらか、縁のなめらかさ | 形の縁の画素を被覆率で背景と混ぜること | アンチエイリアス |
| ピクセル（単体で） | シェーダーの距離と、外へ広げて描く幅の単位 | 物理ピクセル |
| シート | 形を並べて描くテストの画像 | テストパターン |
| 期待画像（目で見る用） | 基準の画像と比べない、描いた結果の PNG | 描いた画像 |
| 塗り | テストの、形の内側の色 | 前景 |
| 前景の割合 | 画素を形が覆う割合 | 被覆率 |

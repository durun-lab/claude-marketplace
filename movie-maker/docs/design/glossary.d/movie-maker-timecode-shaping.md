## 文字

| 用語 | 定義 | 識別子 |
|---|---|---|
| 再生位置のタイムコード | 見出しの列の上の角と、再生の操作のバーのタイムコードの行の左の欄に出すタイムコード。再生中に毎フレーム変わるので、ほかの文字と分けて置き、1 字ずつキャッシュしたシェーピングの結果を並べて、頂点を別のバッチで作る。全体の長さ、イン点、アウト点のタイムコードは入らない | `timeline_timecode`、`transport_timecodes`、`place_timecode`、`clear_tooltip_labels` |
| 等幅の数字 | 0〜9 を一番広い数字の送り幅で並べ、狭い数字をその幅の中央に置く並べ方。CSS の `font-variant-numeric: tabular-nums`（OpenType の `tnum`）と同じ見た目 | `TextMeasure::timecode_stops`、`ShapeCache::timecode_advance` |
| 送り幅 | 字を置いてから、次の字の左端まで進める幅（advance）。空白も幅を持つ | `Shaped::advance` |
| バッチ（文字の描画の） | glyphon の頂点とアトラスの一組。再生位置のタイムコードとほかの文字で分け、変わったバッチだけ頂点を作り直す。アトラスもバッチごとに持ち、片方の頂点を作るときに、もう片方の頂点が指すグリフを追い出さない | `Batch`、`TextStats::uploads`、`TextStats::timecode_uploads` |

## 置き換えた語

### 再生位置のタイムコードのシェーピング

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 時刻の字、時刻の文字、時刻 | 見出しの列の上の角と再生の操作のバーに出す `HH:MM:SS:FF`。用語集の時刻は有理数の時間の位置で、目盛りの時刻とも紛れる | 再生位置のタイムコード |
| 今の時刻 | 再生の操作のバーのタイムコードの行の左の欄 | 再生位置 |
| Timeline の角 | 見出しの列の上の角。Timeline の矩形の四隅のどれか分からない | 見出しの列の上の角 |
| 覚える、覚えた字、覚えたグリフ | 1 字ずつのシェーピングの結果を残して使い回すこと。用語集で「キャッシュする」に置き換えた語 | キャッシュする、キャッシュした字、キャッシュしたシェーピングの結果 |
| 数字の幅をそろえる、`tabular`、`Label::tabular`、`place_tabular`、`tabular_stops`、`push_tabular` | 数字を一番広い数字の幅で並べること。`tabular` は「表の」とも読め、何の幅かが名前に無い | 等幅の数字（`place_timecode`、`TextMeasure::timecode_stops`、`each_glyph`）。`Label` には持たせず、ほかの文字と分けた並びで渡す |
| 升 | 数字を置く、一番広い数字の幅の範囲 | 一番広い数字の送り幅 |
| 字の並びの幅 | `Shaped::advance` | 送り幅 |
| 字ごとの並べ | 1 字ずつのシェーピングの結果を並べる描き方 | 1 字ずつ並べる描き方 |
| `ShapeCache::advance` | 再生位置のタイムコードの字の送り幅。何の送り幅か（等幅の数字か）が名前に無い | `ShapeCache::timecode_advance` |
| 試験 | テスト | テスト |

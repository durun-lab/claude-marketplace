## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| 置く画面 | パックの部品を置くコンポジションの幅と高さ（画素）。プロジェクトに無いコンポジションは本編の画面 | `mm_pack::screen::Screens::of` |
| 基準点（文字のスタイルの） | 文字の塊のうち位置に合わせる点（幅と高さの割合。左上が 0、右下が 1）。置く画面が本編の画面と違うときは、同じ割合の画面の点からのずれを保って位置を変換する | `TextStyleSpec::anchor`、`mm_pack::screen::pin` |
| 縁の固定（引数の） | 本編の画面の画素で書いた座標の引数の既定を、置く画面へ変換するときに保つ縁（軸と、基準点と同じ割合）。引数を渡したときは変換しない | `ParamDef::pin`、`macros/*.json` の `pin` |
| 基準の画面（トランジションの） | vlog のトランジションの座標を書いた 1920x1080 の画面。出力の画面を覆うように縦横同じ倍率で変換し、はみ出た所を切る（CSS の `object-fit: cover`） | `REF`、`VIEW`、`view_uv`（`_prelude.wgsl`） |
| 見せ方（レイヤーの） | sequence を置いたレイヤーの再フレーミングと字幕の置き場所。そのコンポジションの画素で書く | `Layer.framing` |

## 置き換えた語

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 写す | 画面の座標を大きさの違う画面へ / 小道具の関数を別のファイルへ | 変換する / コピーする |
| 絵 | 描いたフレーム（テストで比べるもの） | 画像 |
| 被覆 | 形が 1 画素を覆う割合 | 覆う割合 |
| 試験 | 再現のテスト、形の検査 | テスト |

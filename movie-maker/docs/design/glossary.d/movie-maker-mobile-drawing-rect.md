## モバイル版の描き込みと短い動画の URL

| 用語 | 定義 | 識別子 |
|---|---|---|
| 映像の領域（Watch の） | Watch の上に固定した映像の置き場所。縦向きは 16:9、横向きの全画面では画面。デスクトップの Program の領域に当たる | `Stage`、`.stage` |
| 映像の矩形（Watch の） | 映像の領域の中で、コンポジションの縦横比を保って映像が映る矩形。レターボックスの余白を除く。描き込みの座標はこの矩形を 0〜1 に正規化する。デスクトップの映像の矩形と同じ計算 | `fitRect`、`CompSize` |
| 短い動画の URL | 提案の区間の短い動画のキーを入れた URL。提案の 1 件の応答が今のキーで渡す | `clip_url`、`ClipKey::file_name` |

## 置き換えた語

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 枠、16:9 の枠 | Watch の映像を収める 16:9 の所 | 映像の領域 |
| 余白 | 映像の矩形の外（素材の余白と紛れる） | レターボックスの余白 |
| 面、描く面、見せる面 | 描き込みを描く SVG | 描き込みの SVG |
| `frame`、`FrameSize`、`DEFAULT_FRAME` | 描き込みに渡すコンポジションの大きさ（静止画のフレームと紛れる） | `size`、`CompSize`、`DEFAULT_COMP_SIZE` |
| 内容のアドレス | キーを入れた短い動画の URL | 短い動画の URL（キーを入れた URL） |
| 転送 | 古いキーの URL から今のキーの URL へ移すこと | リダイレクト |
| 作り終えたキー | ディスクにある短い動画のキー | 作り終えた短い動画のキー |

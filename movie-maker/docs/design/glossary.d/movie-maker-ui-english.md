## 置き換えた語

### 画面の文言を英語に（E1）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 先頭（スタックの） | 取り消しのスタックで次に戻すトランザクション | 一番上 |
| 列（単体で） | WebView の 3 つの列のうち、再生の操作と Source を置く列 | 中央の列 |
| 領域（画面の） | 矢印のキーを Source に向けるためにクリックする所（用語集の領域は並行開発の単位） | Source |
| 区切り | 出力先のパスの `/` と `\` | パスの区切り文字 |
| 組（単体で） | 同じ出力先を指すレンダーターゲット | レンダーターゲットの組 |

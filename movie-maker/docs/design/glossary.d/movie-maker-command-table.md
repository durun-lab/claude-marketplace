## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| コマンド（UI の） | 人がキーや Tasks の項目から呼び出す、画面の操作 1 つ。コマンドの表（UI の）の 1 行で、呼び出し箇所が ID（`<分類>.<動詞>`）で指す。操作（`Op`）とは別 | `commands::Spec`、`UiCommand` |
| キーの表 | キーの名前とコマンドの ID の組の並び。ID の名前の順に並べる。キーからは ID を引くだけで、実行はコマンドの表（UI の）に任せる | `keys::BINDINGS`、`keys::command_for` |
| 持ち主（UI のコマンドの） | UI のコマンドを実行する所。アプリ（Rust）か、タブを開く WebView のパネル | `commands::Owner`、`UiCommand.panel` |
| 押せる（UI のコマンドが） | いま実行できること。押せないコマンドと表に無いコマンドの Tasks の項目は薄い色で出し、`run_command` は押せないコマンドを拒否する。キーは押せるかを見ずに実行し、編集が拒否した理由を画面に出す | `commands::State`、`UiCommand.enabled` |
| キーの見た目 | キーの表の名前を画面に出す形にしたもの（`Ctrl+KeyZ` は `Ctrl+Z`、`ArrowLeft` は `←`） | `keys::label`、`UiCommand.key_label` |

## 置き換えた語

### UI のコマンドの表（B3）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 入口（画面の操作の） | キーや Tasks の項目のように、人がコマンドを呼び出す所 / 表が持つもの | 呼び出し箇所 / 人が呼ぶコマンド |
| 組（単体で） | コマンドの ID の `.` の前（`clip`、`playback`） | 分類 |
| 領域（Source の） | 再生のキーを Source に向けるためにクリックする所（用語集の領域は並行開発の単位） | Source |
| 断る | `run_command` が表に無い ID と押せないコマンドを実行しないこと | 拒否する |
| 知らない（ID が） | 表に無いコマンドの ID | 表に無い |
| デモ（Shell の） | Tauri の外のブラウザーで開いた本体の画面（デモのページはパネルごとの別のページ） | ブラウザーで開いた画面 |

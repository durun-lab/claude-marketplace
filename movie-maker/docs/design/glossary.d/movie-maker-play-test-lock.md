## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 再生テストのロック | 再生テストを同じデスクトップ（同じログオンのセッション）で 1 つずつ動かす、名前付きのミューテックス。ウィンドウとプロジェクトを開く前に取り、工程が終わったら放す。持っていたプロセスがクラッシュしても OS が放す。ふだんの起動は取らない | `win/play_test_lock.rs`、`Local\movie-maker-play-test`、結果の JSON の `lock` |
| 待ちの上限（再生テストのロックの） | ロックを待つ長さの上限（15 分）。工程の上限の合計（約 10 分と再生の秒数）より長くし、前の 1 本が上限いっぱいまでかかっても待ちきる。超えたら結果の JSON に理由を書き、終了コード 1 で終わる | `TIMING` |
| 放棄されたミューテックス | 持っていたスレッドが放さずに終わったミューテックス（abandoned）。次に待っていたスレッドが持ち、結果の JSON の `lock.abandoned` が真になる | `WAIT_ABANDONED_0` |
| ロックなしで進める | ミューテックスを作れないときに、待たずに再生テストを始めること。結果の JSON の `lock.state` は `unavailable` | `Lock::unavailable` |
| ほかの movie-maker のウィンドウ | 同じデスクトップに見えるウィンドウを持つ、自分以外の movie-maker.exe。順番待ちの再生テストはまだウィンドウを作っていないので入らない | `desktop::other_movie_maker_windows`、`lock.other_movie_makers` |
| 前面のウィンドウを持つプロセス（工程の後の） | 工程が終わった時点で前面のウィンドウを持っていたプロセス。自分なら `self`、ほかなら実行ファイルの名前と pid | `desktop::foreground_owner`、`lock.foreground_at_end` |

## 置き換えた語

### 再生テストのロック（#236）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 試験、通し | `--play-test` の 1 回。用語集で試験はテストに置き換えた語 | 再生テスト |
| 報告、報告の JSON | `--report` に書く JSON。用語集の語は結果の JSON | 結果の JSON |
| PC 全体のロック | `Local\` の名前付きミューテックス。PC 全体ではなく、同じログオンのセッション（同じデスクトップ）で 1 つ | 再生テストのロック |
| 落ちる | 持っていたプロセスやスレッドが放さずに終わること / 専用のスレッドが結果を返さずに終わること | 放さずに終わる / 結果を返さずに終わる |
| 本物（の試験） | テストの中から見た `--play-test` | 実際の再生テスト |
| 絞らずに進める | ミューテックスを作れないとき。何を絞るのかが分からない | ロックなしで進める |
| 台数 | 自分以外の movie-maker.exe の数。台数は機械を数える語 | 数（ほかの movie-maker のウィンドウの） |
| 持ち主（ミューテックスの、前面の） | 前にミューテックスを持っていたプロセスやスレッド / 前面のウィンドウを持つプロセス。用語集の持ち主は UI のコマンドを実行する所 | 持っていたプロセス、持っていたスレッド / 前面のウィンドウを持つプロセス |
| abandoned（文の中） | 持っていたスレッドが放さずに終わったミューテックス | 放棄されたミューテックス |
| 知らせ | 専用のスレッドから待つ側へ送るもの | イベント |
| キャプチャ | マウスのキャプチャー。用語集の表記はキャプチャー | キャプチャー |
| `Entered` | ロックを取ったあとの状態。何に入ったのかが名前に無い | `LockState` |
| `other_instances` | 自分以外の movie-maker.exe の数。何のインスタンスかが名前に無い | `other_movie_maker_windows`（見えるウィンドウを持つものだけを数える） |
| `IMAGE_NAME` | 実行ファイルの名前。image は画像と紛れる | `EXE_NAME` |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 操作の種 | 性質テストで、プロジェクトのデータを見ずに作る操作の元。`materialize` が今のプロジェクトのデータの ID に当てはめて操作にする。操作の組ごとに 1 ファイル | `Spec`、`crates/mm-ops/tests/it/spec/` |
| 生成器（性質テストの） | 操作の種やプロジェクトのデータをランダムに作るもの（proptest の `Strategy`）。組ごとの重みで混ぜる | `arb_spec`、`arb_project` |

## プロジェクトのデータと操作

| 用語 | 定義 | 識別子 |
|---|---|---|
| 有効（レイヤーの） | レイヤーを描き、鳴らし、字幕の元にするかのフラグ。トラックマットに使うレイヤーは無効でもマットとして効く | `Layer::enabled`、`setLayerEnabled` |

## 時間とシーケンス

| 用語 | 定義 | 識別子 |
|---|---|---|
| 始まり（レイヤーの） | コンポジションの時間軸でレイヤーが始まる時刻。0 より前も取れ、その部分は描かない | `Layer::start` |
| キーフレームの時間軸 | パラメータのキーフレームの時刻を測る時間軸。レイヤーのパラメータはコンポジションの時刻、再フレーミングは素材の時刻、タイムリマップはレイヤーの始まりからの時刻。`shiftLayer` はコンポジションの時刻のものだけを動かす | `comp_time_params`（`shift_layer.rs`） |

## 置き換えた語

### レイヤーを前後に動かす操作（B1）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 開始 | レイヤーの `start`（操作の説明、テストの名前） | 始まり |
| 時間の上で動かす | `shiftLayer` の説明 | コンポジションの時間軸で前後に動かす |
| 見出しの目のボタン | `setLayerEnabled` を切り替える画面の部品 | レイヤーの見出しの有効のボタン |
| 目のアイコン（Video） | After Effects の先行事例 | Video のスイッチ（目のアイコン） |
| 操作の口（`mm-*-api` の） | RFC のインターフェースの変更。`mm-ops` は API クレートではない | `mm-ops`（基礎の層）の操作 |
| 既存の経路 | ロックしたレイヤーの拒否。操作経路（CLI、MCP など）と紛れる | ロックの検査（`OpError::Locked`） |
| 複製 | 桁あふれのときに元を書き換えないための、レイヤーのコピー。複製のショートと紛れる | コピー |
| 取り残される | 動かさないキーフレームの様子 | 元の時刻のまま残る |
| 音（動かすキーフレームの並びの） | `shiftLayer` が動かすパラメータ。音のフェードは含まない | 音量とパン |
| レイヤーの時間の操作（`setLayerEnabled` を含めた呼び方） | 性質テストの組の名前 | レイヤーの時間と有効の操作 |
| 頭（カットの、レイヤーの） | `setTransition` の説明（05-ops.md の汎用の操作の行）/ 0 より前に出て描かれない部分 | 先頭 |

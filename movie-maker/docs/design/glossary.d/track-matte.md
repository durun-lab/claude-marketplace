## トラックマット

| 用語 | 定義 | 識別子 |
|---|---|---|
| トラックマット | 同じコンポジションの別のレイヤーの画像（アルファか線形の輝度）で、レイヤーを切り抜く仕組み。レイヤー自身の形で切り抜くマスクとは別 | `Layer.track_matte`、`TrackMatte`、`MatteKind` |
| マットのレイヤー | トラックマットに使われるレイヤー。合成からは外れ、切り抜くレイヤーの被覆率にだけ効く | `TrackMatte.layer`、`matte::matte_layers` |
| 切り抜くレイヤー | トラックマットを持つレイヤー。マットの被覆率を掛けた画像を、自分の合成モードで重ねる | `matte::matted_item` |
| 被覆率 | 画素を見せる割合（0 が隠す、1 が見せる）。マスクは形からの距離、トラックマットはマットのアルファか輝度から決める | `coverage`（`matte.wgsl`、`compose.wgsl`） |
| 画像のマスク | geneva のクリップの `mask.asset`。画像の輝度とアルファの積で切り抜く。`mm geneva` は輝度のトラックマットにする | `geneva_cmd::visual::matte::split` |

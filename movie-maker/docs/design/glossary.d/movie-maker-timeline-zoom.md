## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| ズームバーが表す範囲 | ズームバーの溝の左端から右端までが表す時刻の範囲。コンポジションの全体に見えている範囲を合わせたもので、全体表示の左右の余白や、終わりより右へ動かした表示でもスクロールボックスが溝に収まる | `zoombar::extent` |
| スクロールボックス（ズームバーの） | ズームバーの、見えている範囲を示す矩形。幅の下限は 24 論理ピクセル。中のドラッグで倍率を保って見えている範囲を動かす | `zoombar::thumb`、`ZoomBarPart::Thumb` |
| スクロールボックスの端（ズームバーの） | ズームバーのスクロールボックスの左右の、幅 7 論理ピクセル（スクロールボックスの幅の 1/3 まで）の所。ドラッグで反対の端を保って拡大縮小する。溝の色の縦の線を 2 本ずつ引いて示す | `ZoomBarPart::StartEdge`、`ZoomBarPart::EndEdge` |
| 全体表示の行き来 | Full Extent Zoom（Shift+Z）で全体表示にし、表示を変えないままもう一度呼ぶと前の倍率と位置に戻ること（Resolve の Shift+Z）。間にほかの操作で表示を変えたら、もう一度全体表示にする | `TimelineCommand::FullExtentZoom`、`controller::zoom::FullExtent` |
| ズームの中心（キーとメニューの） | Zoom In と Zoom Out で動かさない時刻。再生位置で、見えていなければ拡大した後に再生位置を行の領域の中央に置く。Ctrl+ホイールの中心はポインター | `TimelineController::zoom_at_playhead` |
| ページ送り（再生中の） | 再生中に再生位置が行の領域の右端を越えたら、越えた先が見えるまで見えている範囲を 1 画面ずつ送ること（Premiere の Page Scroll）。右端の外にあった再生位置が進んでも送らない | `TimelineController::page_scroll`、`Ui::set_playing` |
| 前後の帯の端（Previous Edit と Next Edit の移動先） | 再生位置の前か後ろの、いちばん近いレイヤーとカットの始まりと終わり、0、終わり。フレームの境目に丸め、最後のフレームの始まりまでに収める。半フレームより近い端は今いる所として飛ばす | `edit_target` |
| Timeline のコマンド | キーとメニューから Timeline に送る UI のコマンド（拡大縮小、全体表示、前後の帯の端）。描画スレッドの Timeline が実行する | `TimelineCommand`、`Action::Timeline`、`Shared::timeline_commands` |
| 名前で引くキー / 記号のキー | キーの名前を `KeyboardEvent.code` の名前で作るキー（英字、数字、矢印、Space、Home、Delete、F1 など）/ 押された文字で作るキー（`=`、`-`、`,`、テンキーなど）。記号は配列でキーの位置が違うので文字で引き、Shift は名前に付けない | `keys::vk_name`、`keys::symbol_name`、`keyName` |
| 押された文字（記号のキーの） | 記号のキーを今の配列で、Shift だけを押した状態で文字にしたもの。サーフェスは `ToUnicodeEx`、WebView は `KeyboardEvent.key` | `surface::key_name_in` |

## 置き換えた語

### UI の分かりやすさ（Timeline のズーム）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| つまみ（ズームバーの） | ズームバーの見えている範囲を示す矩形。「つまみ」は帯の端のつまみと紛れる | スクロールボックス（ズームバーの） |
| ハンドル、つまみ（スクロールボックスの両端の） | ズームバーのスクロールボックスの、掴むと拡大縮小する左右の所 | スクロールボックスの端 |
| 全体の長さ（ズームバーの） | ズームバーの溝が表す時刻の範囲。全体表示の余白と、終わりより右へ動かした表示も含む | ズームバーが表す範囲 |
| 編集点（Previous Edit と Next Edit の） | 再生位置を動かす先。用語集の編集点はカットの間だけで、レイヤーの端と 0 と終わりを含まない | 前後の帯の端 |
| キーの文字、記号の名前 | 記号のキーの名前にする、今の配列で押された文字 | 押された文字 |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| テストの一時フォルダー | テストが作り、使い終わったら消すフォルダー。`tempfile::Builder` の `prefix` で作り、名前の後ろに乱数が付く。ガード（`TempDir`）を使い終わるまで変数に持つ。`temp_dir()` にプロセスの ID だけを足した名前は、前の実行が残したフォルダーと同じ名前になるので使わない（`scripts/check-conventions.sh` が拒否する） | `tempfile::TempDir`、`tempfile::Builder` |
| 前の実行が残したフォルダー | 前に同じ pid だったプロセス（クラッシュしたアプリ、止めたテスト）が消さずに残した一時フォルダー。Windows は pid を使い回すので、pid だけで決めた名前はこれと同じ名前になる。ホストの一時フォルダーはその名前を使わずに次の番号で作り、ランチャーなしで動くホストは開く前に消す | `create_fresh_dir`、`host::start` |

## 置き換えた語

### テストの一時フォルダー（#228）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 試験 | check-conventions.sh の検査の文言、`temp_file` の doc コメント、PR の題と本文。用語集で試験はテストに置き換えた語 | テスト |
| 守る（一時フォルダーを） | `render_stage0` が返す `TempDir`。用語集で守りはガードに置き換えた語 | ガード（ドロップされると出力先ごと消す） |
| 作業フォルダー（ホストの） | ランチャーがホストごとに作って渡すフォルダーと、ランチャーなしで動くホストが自分で決めるフォルダー。用語集の語は一時フォルダー | ホストの一時フォルダー |
| 本番のコード | ホストの実行ファイルとランチャーのコード。テストの一時フォルダーと分けるための語 | テストではないコード（ホストとランチャー） |
| 残り（前の実行の、同じ名前の） | 前に同じ pid だったプロセスが消さずに残したフォルダー。「残り」だけでは残りの量や残りの項目と紛れる | 前の実行が残したフォルダー |
| 漏れ（一時フォルダーの） | 止めたホストの一時フォルダーを消さずに残すこと。ハンドルの漏れ（`StaleHandles::Count`）と紛れる | 消し忘れ |
| 重なる（名前が / pid が） | 同じ名前になること / 生きているプロセスの間に同じ pid が無いこと。用語集で重なる（ID が）は重複するに置き換えた語 | 同じ名前になる / 重複する |
| 名前が残っていた | 作ろうとした名前のフォルダーが既にあること | 同じ名前のフォルダーがあった |
| `stem` | ホストの一時フォルダーの名前の、番号より前の部分（`mm-<名前>-<pid>`） | `prefix`（接頭辞） |
| `_da`、`_db` | `temp_file` が返すガード。何の値かが名前に無い | `_dir_a`、`_dir_b` |

## GPU の選択

| 用語 | 定義 | 識別子 |
|---|---|---|
| GPU の指定 | 使う GPU を 1 つに決める文字列。名前の一部（大文字小文字を区別しない）、`luid:<16 進>`、`index:<番号>` のどれか。環境変数 `MM_GPU` と、CLI とホストの GPU の引数が同じ書き方 | `GpuSelector`、`GPU_ENV` |
| LUID | Windows がアダプターに振る 64 ビットの識別子。起動のたびに変わりうるが、動いている間はプロセスをまたいで同じ GPU を指す | `GpuAdapterId::luid` |
| アダプターの候補 | デバイスを作らずに分かる GPU の記述（名前と LUID）。指定と照らし、合わないときのエラーに一覧で出す | `AdapterCandidate` |

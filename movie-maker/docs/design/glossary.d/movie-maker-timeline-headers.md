## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 見出しの列の上の角 | 見出しの列の上、目盛りの帯の左の矩形。再生位置のタイムコードと、Shy の行の数（T3）を出す。押しても選択を変えない | `TimelineLayout::corner`、`Hit::Corner` |
| タイムコード | 時刻を `HH:MM:SS:FF`（時、分、秒、フレーム）で書いたもの。フレームはその時刻を含むフレーム（切り捨て。WebView の Frame の数と同じ）で、1 秒のフレームの数はフレームレートを丸めた数（ノンドロップ） | `header::timecode` |
| 見出しの部品 | レイヤーの見出しの 1 行に並ぶ、種類の色の帯、種類の略号、名前、有効のボタン、ロックのボタン、Mute と Solo のボタン、キーフレームの開閉の矩形。描く関数と文字が同じ矩形を見る | `header::Cells`、`header::cells` |
| 種類の色の帯（レイヤーの見出しの） | 見出しの左端の、帯と同じ種類の色の細い矩形。無効なレイヤーは薄い | `Cells::kind_strip` |
| 音を持てるレイヤー | 撮影素材、入れ子、sequence のレイヤー。Mixer のトラックになり、見出しに Mute と Solo のボタンを出す。音の設定（`Layer::audio`）が無ければ既定（Mute も Solo も切） | `AUDIO_KINDS`（`mm-ui-wgpu` の `model.rs`）、`AudioState`、`Item::audio` |
| Mute と Solo のボタン | 音を持てるレイヤーの見出しの M と S。入は Mixer と同じテーマの色（Mute は `danger`、Solo は `accent`）で塗り、切は薄い枠と字 | `Palette::mute`、`Palette::solo`、`paint/header.rs` の `audio_button` |
| アイコン（見出しのボタンの） | 有効のボタンの目の形と、ロックのボタンの鍵の形。入は明るく、切は薄い | `header::mark_color`、`paint/header.rs` の `eye`、`lock` |
| スクラブの許容誤差（`--play-test` の） | ルーラーのクリックでのシークの結果と狙った時刻の差の上限。クリックを物理ピクセルに丸めた半画素と、シークをフレームに丸めた半フレームの和で、下限は 2 フレーム | `scrub_tolerance`、`scrub_tolerance_secs` |

## 置き換えた語

### UI の分かりやすさ（レイヤーの見出し）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 角 | 見出しの列の上、目盛りの帯の左の矩形。「角」だけでは Timeline のどの角か分からない | 見出しの列の上の角 |
| 時刻（角の） | 見出しの列の上の角に出す `HH:MM:SS:FF`。目盛りの時刻（`0:06`）と紛れる | タイムコード |
| 部品 | 見出し 1 行の帯、略号、名前、ボタンの矩形。「部品」だけでは UI のどの部品か分からない | 見出しの部品 |
| 印 | 有効とロックのボタンの目と鍵の形。用語集の「印」はマーカーやフラグに置き換えた語 | アイコン（見出しのボタンの） |
| 地、地の色 | 入の Mute と Solo のボタンの塗り | 背景（ボタンの） |
| 点いている、押されている / 切れている | Mute、Solo、有効、ロックの状態 | 入 / 切 |
| つる | 鍵の形のアイコンの上の U 字の部分 | U 字の金具（鍵の形の） |
| チップ、四角、`chip`、`CHIP`、`chip_text` | Mute と Solo のボタンの枠と背景 | Mute と Solo のボタン（`audio_button`、`AUDIO_BUTTON`、`audio_button_text`） |
| 帯、`Cells::stripe`、`STRIPE_W` | 見出しの左端の種類の色の矩形。レイヤーの帯と、行の縞（`paint::stripe`）と紛れる | 種類の色の帯（`Cells::kind_strip`、`KIND_STRIP_W`） |
| `band` | 見出しの行の背景の矩形。英語の band が「帯」と読める | 行の背景（`back`） |
| 境の線 | 行と行の間の 1 px の線 | 行の境界の線 |
| 音のあるレイヤー、音の無いレイヤー | Mute と Solo を出すレイヤー。実際に音があるかでなく、レイヤーの種類で決まる | 音を持てるレイヤー、音を持てないレイヤー |
| 見えている所（`header::visible`） | 見出しの部品の矩形のうち、見出しの列に入る所。用語集の「見えている所（Timeline の）」（`Viewport`）と紛れる | 見出しの列に入る所（`header::inside`） |
| 見出しのボタンの PR、この PR | コードのコメントで後の PR と今の PR を指す言い方。PR が入ると古くなる | 今の動作を書く（後の PR は設計書の T3） |

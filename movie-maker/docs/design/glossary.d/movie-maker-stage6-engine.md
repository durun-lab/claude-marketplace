## ホストと構造

| 用語 | 定義 | 識別子 |
|---|---|---|
| ホストの接続 | ホストを子プロセスで起こし、`mm-host-api` のプロトコルを 1 行ずつ往復するアプリ側の共通実装 | `mm-host-pipe`、`PipeHost` |
| ホストの起こし方 | ホストの実装ごとの違い（名前、起動の期限、一時フォルダー、読み捨てる応答の共有ハンドルの扱い、子の環境） | `PipeKind`、`StaleHandles` |
| 一時フォルダー | ランチャーがホストごとに作って渡し、止めた後に消すフォルダー。CEF のキャッシュとページを置く | `MM_HOST_WORK_DIR`、`remove_work_dir` |
| ジョブ | ホストとホストが起こしたプロセスの木をまとめて止める Windows のジョブオブジェクト。アプリがクラッシュしても木が止まる | `mm_host_pipe::Job`、`kill_tree` |

## ホストと構造

| 用語 | 定義 | 識別子 |
|---|---|---|
| ホストの接続 | ホストを子プロセスで起こし、`mm-host-api` のプロトコルを 1 行ずつ往復するアプリ側の共通実装 | `mm-host-pipe`、`PipeHost` |
| ホストの起こし方 | ホストの実装ごとの違い（名前、起動の期限、一時フォルダー、読み捨てる応答の共有ハンドルの扱い、子の環境） | `PipeKind`、`StaleHandles` |
| 一時フォルダー | ランチャーがホストごとに作って渡し、止めた後に消すフォルダー。CEF のキャッシュとページを置く | `MM_HOST_WORK_DIR`、`remove_work_dir` |
| ジョブ | ホストとホストが起こしたプロセスの木をまとめて止める Windows のジョブオブジェクト。アプリがクラッシュしても木が止まる | `mm_host_pipe::Job`、`kill_tree` |
| 時間切れ（ホストの） | 期限までに応答が来ないこと。続けて起きたホストは止めて捨て、次の要求で起こし直す | `MmError::Timeout`、`MAX_TIMEOUTS` |
| 1 フレームの期限 | ホストが 1 回の `RenderFrame`（時刻の反映、画像と書体の待ち、フレームが来るまで）にかける上限。アプリの期限より短くし、理由を応答で返す | `FRAME_LIMIT` |
| sandbox | CEF の子のプロセスの権限を絞る仕組み。`bundle.sh` で組んだホストだけが使う | `PROBE_SANDBOX` |
| 能力の問い合わせ | `mm-host-cef probe` で `cef` の feature と sandbox の有無を聞くこと | `probe_reply`、`supports_cef` |
| 通すページ | 遷移と資源の要求を許す、ホストが書いたページのファイルとその URL | `Allowed`、`policy::is_file_url_of` |
| フレームの受け取りの経路 | `web.cef` がホストからフレームを受け取る方法（CPU の画像か共有テクスチャ） | `FrameTransport` |

## OpenFX

| 用語 | 定義 | 識別子 |
|---|---|---|
| バンドル | OpenFX のプラグインのフォルダー（`<名前>.ofx.bundle`） | `PrepareParams::bundle`、`describe_bundle` |
| 文脈 | プラグインの使われ方（Filter、Generator など） | `FX_CONTEXT` |
| 深さ | 画素の 1 成分のビットの深さ（Byte、Short、Float） | `Depth` |
| suite | ホストがプラグインに渡す関数の表 | `host/suites.rs`、`fetchSuite` |
| 記述子 | describe でプラグインが書き込むプロパティの組 | `Described` |

## 描画と文字

| 用語 | 定義 | 識別子 |
|---|---|---|
| トランジション | 編集点の前後に半分ずつ掛け、出ていくカットと入ってくるカットを混ぜる効果。長さと種類を持つ | `Cut.transition_in`、`setTransition` |
| 素材の余白 | カットのイン点の前とアウト点の後ろにある素材の長さ。トランジションが延ばせる幅を決める | `Handles`、`handles_in` |
| 逆向きに描く | 出ていくカットを、掛かり始めから倍率つきで時間を戻して描くこと | `rewind`、`rewind_rate` |
| ぼかし（マスクの） | マスクの縁を柔らかくする幅（画素） | `Mask.feather` |
| ふりがなの場所 | ルビを含む行の上にシェーパーが空ける高さ（字の大きさ × `RUBY_SCALE`） | `mm_text_glyphon::room`、`RUBY_SCALE` |
| 縁の太さの上限 | 縁取りの太さを丸める上限（64 px） | `TextStroke::MAX_WIDTH_PX`、`clamped_width` |

## 置き換えた語

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| カットの頭 | トランジションの置き場所 | カットの先頭 |
| 境、カットの境 | カットの間 | 編集点 |
| フレームの境、コマの境 | 書き出しの区間の端 | フレームの境界 |
| 列 | マスク、頂点、操作 | 並び |
| 余白（ハンドル） | トランジションが延ばせる素材 | 素材の余白 |
| 試験、検査 | テスト | テスト |
| 走らせる | describe や probe の実行 | 実行する |
| 落ちる、落とす | プラグインやアプリの異常終了 / テストの失敗 | クラッシュする / 失敗する |
| 写し、写す | 画素や記述子 | コピー、コピーする |
| 飛ばす | 読めない書体、プラグイン、マスク | スキップする |
| 印 | probe の答えの sandbox / テストの画素 | 文字列 / 白い矩形 |
| 入口、受け口 | sandbox つきの起動の DLL / OpenFX の C API | エントリーポイント / ブリッジ |
| 約束 | 受け渡しの決まり | 規約 |
| 当て直す | 伝達関数 | 適用し直す |
| 覚える | 描いた画像 / 起きたこと | キャッシュする / 記録する |
| 記号（`｜`） | ルビの注記 | 縦線 |
| 段 | 文字の描き方の表 | 工程 |
| ハンドラ、ブラウザ、レンダラ | CEF | ハンドラー、ブラウザー、レンダラー |
| `Delivery`（`web.cef` の） | フレームの受け取り方。納品物の `Delivery` と重なる | `FrameTransport` |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| Keyboard Shortcuts のウィンドウ | `?` と Help > Keyboard Shortcuts… で開く、全部のコマンドとキーの一覧。名前とキーで絞り込み、Enter で実行する。メインウィンドウをオーナーにした別のウィンドウ | `shortcuts_window.rs`、`ui/shortcuts/`、`app.show_keyboard_shortcuts` |
| メインウィンドウ | メニューバー、サーフェス、右の WebView を持つアプリのウィンドウ（Tauri の label `main`）。メインウィンドウ自身は、子 HWND ではないトップレベルの HWND | `layout::create_window` |
| オーナー（ウィンドウの） | Windows の owned window の持ち主。持たれたウィンドウはオーナーより手前に出続け、オーナーを閉じると一緒に閉じる | `WebviewWindowBuilder::owner_raw` |
| 前面に出す | ウィンドウを手前に出し、キーを受けるウィンドウ（Windows の foreground window）にする | `set_focus` |
| 区画（Keyboard Shortcuts のウィンドウの） | メニューの画面の名前か Other を見出しにした、コマンドの行のまとまり。メニューバーの中の位置の順に並ぶ | `Section`、`sections` |
| メニューバーの中の位置 | コマンドが入っている最初のメニューと、メニューとグループをまたいだ通し番号。メニューの並びから作る | `menu::place_of`、`UiCommand.menu_order` |
| 全部のキーの見た目 | コマンドに割り当てた全部のキーの見た目。並びはキーの表と同じで、先頭がメニューとツールチップに出すキー | `UiCommand.key_labels` |
| 外側の大きさ（ウィンドウの） | タイトルバーと縁を含むウィンドウ全体の大きさ。クライアント領域の大きさとは別 | `outer_size` |
| 作業領域（モニターの） | モニターのうちタスクバーを除いた所（Windows の work area）。Keyboard Shortcuts のウィンドウは、はみ出す分だけ中へ寄せる | `Monitor::work_area`、`shortcuts_window::place` |

## 置き換えた語

### Keyboard Shortcuts のウィンドウ（D2）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 本体、本体のウィンドウ | Keyboard Shortcuts のウィンドウのオーナーで、中央に重ねる先 | メインウィンドウ |
| 前に出す、前に出る | 開いているウィンドウを手前に出してキーを受けさせること / ウィンドウがキーを受けるようになること | 前面に出す、前面に出る |
| 前に出し続ける、前に出続ける | オーナーより手前の重なりに置かれ続けること | 手前に置き続ける、手前に出続ける |
| 組（メニューの組、最後の組 Other） | Keyboard Shortcuts のウィンドウで、見出しの下にコマンドの行をまとめたもの。用語集で組は分類と区画に置き換えた語 | 区画 |
| 組（Shotcut の） | Shotcut の Actions and Shortcuts が操作の名前の前に付けるメニューの名前 | メニューの名前を付ける |
| `order_of`、メニューの中の位置（グループをまたいだ通し番号） | メニューごとに 0 から数えた位置。メニューの順を別にページが持つ必要があった | `place_of`、メニューバーの中の位置（メニューとグループをまたいだ通し番号） |
| 外形 | タイトルバーと縁を含むウィンドウの大きさ | 外側の大きさ |
| 中の大きさ（ウィンドウの） | タイトルバーと縁を除いた大きさ | クライアント領域の大きさ |
| フレーム（ウィンドウの） | メインウィンドウのトップレベルの HWND。動画のフレームと紛れる | メインウィンドウ自身 |
| 活性 | ウィンドウがキーを受ける状態になること（`WM_ACTIVATE`） | アクティブ（になる）、アクティブ化 |
| 返り（メインスレッドの） | ウィンドウを作るときに、メインスレッドが処理を終えて返すこと | 応答 |
| 版（`windows` クレートの） | Tauri と movie-maker が使う `windows` クレートの違い。用語集で版はバージョンに置き換えた語 | バージョン |
| 印（アクセスキーの、薄い印） | メニューの名前でアクセスキーの字の前に置く `&` / 押せないコマンドを薄く出すこと。用語集で印はマーカーとフラグに置き換えた語 | アクセスキーを示す記号 / 薄く出す |
| 選び | 上下の矢印で選んだ行 | 選んだ行 |

## ホストと構造

| 用語 | 定義 | 識別子 |
|---|---|---|
| 共有メモリ | アプリとホストが名前で同じ区画を開き、画像と音のブロックを JSON やパイプを通さずに渡す仕組み。中身を触ってよいのは番を持つ側だけで、番の受け渡しはパイプの要求と応答かイベントで行う | `mm_host_pipe::shm`、`Mapping`、`Event` |
| マジック（共有メモリの） | 共有メモリの先頭に書く、中身の形と取り決めのバージョンを開いた側が確かめる値 | `audio::block::MAGIC`、`LAYOUT_VERSION` |
| プラグインの置き場所 | プラグインの種類が読んでよいフォルダーの一覧。名前は `..` やドライブを含まない相対の名前か、置き場所の中の絶対パスに限り、実体のパスが外にあれば拒否する | `resolve_in_roots`、`PluginStandard::plugin_dirs`、`OFX_PLUGIN_PATH`、`CLAP_PATH` |
| 規格（音のプラグインの） | CLAP と VST3 のように、プラグインの読み込みの決まりを持つ種類の違い。種類の名前、ホストの実行ファイル、拡張子、置き場所を規格ごとに持ち、アプリ側の種類と別プロセスのホストの共通実装が共有する | `PluginStandard`、`PluginEffectKind<S>` |
| describe | プラグインのファイルを別プロセスのホストで列挙し、JSON を 1 行で出す操作。壊れたプラグインを読んでもアプリが止まらない | `run_describe`、`DESCRIBE_COMMAND` |
| 共有ライブラリの読み込み | プラグインの DLL を読み込む。依存の DLL はプラグインのフォルダーとシステムのフォルダーだけから探し、カレントと `PATH` の同名の DLL を読まない。呼ぶのは別プロセスのホストに限る | `mm_host_pipe::load_library` |
| スタンプ（バンドルの中身の） | バンドルの `Contents/<アーキテクチャ>/` の直下のファイルの名前、大きさ、更新時刻から作る文字列。中身が変われば変わり、describe の結果のキャッシュと読み込んだホストの使い回しを見直す | `stamp`、`mm-nodes-ofx` の `catalog` |

## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| 音の効果 | レイヤーの `effects` に置き、レイヤーの音に上から順にかける種類。ブロックをその場で変える | `NodeKind::process_audio`、`audio.clap`、`audio.vst3`、`PluginEffectKind` |
| 種類の指紋 | パラメータと素材の外にあって画素を変えうる入力を表す文字列（`ofx` のバンドルの実体のパスとスタンプと効果の識別子）。レンダラーがフレームのキャッシュのキーに入れ、`None` ならそのフレームをキャッシュしない。素材の短いハッシュである「指紋」とは別 | `NodeKind::cache_fingerprint` |
| パラメータの組ごとの定義 | 渡したパラメータの組のときのパラメータの定義。選んだもので一覧が変わる種類が、`params()` の後ろに選んだものの分を足して返す | `NodeKind::params_for` |
| 素材をデコードする種類 | `AssetRef` の素材をレンダラーがデコーダーで開いて渡す種類。素材のファイルを自分で読む種類は偽を返し、パスを自分で引く | `NodeKind::decodes_asset` |
| 種類の一覧 | 登録されているノードの種類の名前、バージョン、性質、入力、パラメータの定義。MCP の `kinds` で、パラメータの組を渡すと `params_for` の結果で返す | `kinds`、`describe_kinds`、`KindQuery`、`KindInfo` |

## デコードと色

| 用語 | 定義 | 識別子 |
|---|---|---|
| 広い信号の素材 | 8 bit を経由せずに線形にする素材。8 bit を超える、PQ か HLG、Rec.2020 の原色のいずれか | `is_wide`、`Transfer::is_hdr` |
| 画素の作り方のバージョン | 同じ入力でも画素が変わる作り方を変えたときに上げる文字列。フレームのキャッシュのキーに入り、該当する画像だけが描き直される。デコーダーの実装の名前の末尾、`color.lut` の定義域の外の扱い、OCIO のベイクが持つ | `wide_backend_id!`、`LUT_PIXEL_VERSION`、`BAKE_VERSION` |
| 定義域（`color.lut` の） | LUT が入力を受ける 0..1 の範囲。外の値は端の値に足して持ち越し、1 を超える HDR の値を切らない | `color.lut` |

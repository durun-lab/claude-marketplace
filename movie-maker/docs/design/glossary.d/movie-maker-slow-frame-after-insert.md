## デコードと色

| 用語 | 定義 | 識別子 |
|---|---|---|
| 素材を開くのを待つ上限 | 1 フレームの描画で、素材を開き終わるのを待つ長さの上限（アプリのプレビューは 100 ms）。開き始めたフレームだけ待ち、超えた素材はバックグラウンドのスレッドで開き続ける。`None` は開き終わるまで待つ（書き出し、CLI、配信） | `RuntimeConfig::open_wait_ms`、`WgpuRenderer::with_open_wait` |
| 開いている途中（素材の） | バックグラウンドのスレッドで素材を開いていて、描画を呼ぶスレッドがまだデコーダーを受け取っていない状態。そのフレームではそのレイヤーを描かない | `Footage::Pending`、`source/opening.rs` |
| 描かなかったレイヤー（素材を開いている途中の） | 直前のフレームで、素材を開いている途中のために除いて描いたレイヤー。再生スレッドが数を読み、止まっている間も開き終わったら今のフレームを描き直す。除いたまま描いた入れ子の画像はキャッシュに覚えない | `PendingSources::layers`、`Engine::pending_layers`、`Player::redraw_opened` |
| 走査（PTS の索引の） | 素材の全パケットを読んで PTS の索引を作ること。大きな素材（256 MiB 以上）の走査は処理全体で一度に 1 つ | `scan_video`、`index_cache::cached_or_scan`、スパン `decode.scan_index` |
| 走査のロック | 大きな素材の走査を処理全体で一度に 1 つにするロック。小さな素材（画像、短い素材）は取らない | `index_cache::SCANNING`、`scan_lock` |
| 索引の置き場所 | PTS の索引を置くキャッシュ。処理全体で 1 つで、最初に組んだ `Engine` のキャッシュを処理の終わりまで使う（Source、パック、書き出し、配信の `Engine` を後から組んでも置き直さない） | `index_cache::init_index_cache`、`set_index_cache` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 編集の結果の取り込み（再生スレッドの） | 再生スレッドが編集の結果のプロジェクトのデータを描画に取り込み、今のフレームを描き直すこと。回数を数え、再生テストが insert の後に描き直すまでの時間を測る | `Player::adopt_project`、`Shared::adopted`、`redraw_after_first_insert` |
| 開いている途中の印 | 素材を開いている途中のレイヤーを除いたフレームを出している間、ビューアー（Program、Source）の左上に出す「Media Pending」の文字と、その下に敷くパネルの色の矩形（Premiere Pro の Media Pending に倣う） | `pending_badge`、`MEDIA_PENDING`、`Ui::set_program_pending`、`Ui::set_source_pending`、`PreviewFrame::pending` |

## 置き換えた語

### 素材を開くのを待たない描画（insert の後の遅いフレーム）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| 裏で開く、裏のスレッド | 素材を開くスレッド。用語集で裏はバックグラウンドに置き換えた語 | バックグラウンドのスレッドで開く |
| 知らせ（開いている途中の） | 描かなかったレイヤーの数と開き終わった数。イベントではなく、再生スレッドが読む数 | 描かなかったレイヤーの数、開き終わった数 |
| 描画のスレッド（レンダラーの） | アプリの描画スレッド（サーフェス）と紛れる。レンダラーを呼ぶのはアプリでは再生スレッド | 描画を呼ぶスレッド（アプリでは再生スレッド） |
| 抜く（レイヤーを描画から） | 開いている途中のレイヤーを、そのフレームに描かないこと。`mm-ops` の「抜く」は extract と lift でカットを取り去ること（後ろが詰まる）で、紛れる | 除く（除いて描く） |
| 順番（大きな素材の走査の） | 走査を一度に 1 つにするミューテックス。どの素材を先に読むかの順と紛れる | 走査のロック |
| 受け口（結果を返す） | バックグラウンドのスレッドの結果を受け取るチャンネルの端。用語集で受け口はハンドラーに置き換えた語 | 受け手（`Receiver`） |
| 道具（素材を開く） | デコーダーのファクトリーと GPU のコンテキストの組 | 素材を開くのに要るもの（`Opener`） |
| 持ち主の参照 | バックグラウンドのスレッドへ渡せるよう `Arc` で持つこと | 共有の参照（`Arc`） |
| 数え（レイヤーの） | 動詞の連用形を名詞にした語。数そのもの | 数（描かなかったレイヤーの数） |

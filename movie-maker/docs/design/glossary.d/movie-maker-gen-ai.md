## ノードと描画

| 用語 | 定義 | 識別子 |
|---|---|---|
| 提供元（生成 AI の） | 画像・動画・音を生成するサービス 1 つ。差し替えられる層の実装で、テストにはモックの提供元を使う | `Provider`、`FakeProvider` |
| 頼み（生成の） | `gen.ai` のパラメータから作る生成の内容。提供元のバージョンと合わせた BLAKE3 を頼みのキーと呼び、同じキーの素材を使い回す | `GenRequest`、`GenRequest::key` |
| 見積もり（生成の） | 生成の前に提供元の料金表から出す費用と時間。使い回すときは 0 | `Quote`、`Estimate` |
| 承認（生成の） | 人が見積もりを承認した記録。頼みのキーと費用の上限を持つ。Claude の経路（MCP と CLI）と自動の改善の回の中からは作れない | `Approval`、`GenAi::approve` |
| 回の環境変数 | 自動の改善の回の `claude -p` とその子に渡す環境変数。費用のかかる操作はこれを見て拒否する | `MM_IMPROVE_RUN`、`mm_improve::ROUND_ENV` |

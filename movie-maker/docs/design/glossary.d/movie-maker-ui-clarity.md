## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| コマンドの表（UI の） | 画面の操作の一覧。ID、英語の名前、キー、説明、メニューの場所、持ち主（Rust か WebView のパネル）、押せるかを持つ。メニュー、ツールチップ、Keyboard Shortcuts のウィンドウ、ステータスバー、Tasks が同じ表を読む。データの変更は操作（`Op`）のまま | `commands.rs`、`run_command` |
| 割り付け（ウィンドウの） | ウィンドウをサーフェスと WebView の矩形に分けたもの | `split_rects`、`win/layout.rs` |
| 仕切り | 割り付けの境界（サーフェスと WebView の境界、Program と Timeline の境界）。ドラッグで動かす | `win/layout.rs` |
| Diagnostics | 開発の情報（GPU、実装、通知の遅れ、時計、レイヤーの生の一覧）を出すパネル | `ui/panels/diagnostics` |
| Keyboard Shortcuts のウィンドウ | `?` で開く別のウィンドウ。コマンドを名前とキーで探して実行する | `ui/shortcuts` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| レイヤーの行（Timeline の） | Timeline でレイヤー 1 本を表す横長の行。帯とレイヤーの見出しを持ち、上が前のレイヤー。ほかのソフトのトラックにあたる | `row_top` |
| レイヤーの見出し | レイヤーの行の左端の、種類の色と略号、名前、有効のボタン、ロックのボタン、Mute と Solo のボタン、▸ を並べた所。ほかのソフトのトラックの見出し（track header）にあたる | `header.rs` |
| 種類の略号（レイヤーの見出しの） | V: Footage、I: Image、T: Text、S: Solid、C: Composition、Seq: Sequence。Other は無し | `ItemKind` |
| 有効のボタン / ロックのボタン | レイヤーの見出しの、`setLayerEnabled` を切り替える目の形のボタン / `lockLayer` を切り替える鍵の形のボタン | `header.rs` |
| 行の高さ（Timeline の） | レイヤーの行の 3 つの高さ（Small 18、Medium 28、Large 56 論理ピクセル）。高さに応じて、帯に名前、先頭のサムネイル、フィルムストリップ、波形を出し分ける | `RowHeight` |
| 表示の状態（Timeline の） | ズーム、スクロール、行の高さ、Shy、スナップの入/切。プロジェクトのデータに入れず、取り消しの列と `versions/` にも入らない | `.mm/view.json` |
| Shy | Timeline の表示からだけ外すレイヤーのフラグ（AE の Shy）。描画と書き出しは変わらない | 表示の状態 |
| ツールバー（Timeline の） | Timeline の上端の横長の領域。取り消し、ツール、編集、スナップ、ズームのボタンを並べる | `toolbar.rs` |
| ツール（Timeline の） | 帯の中と端のドラッグが何をするかを決める状態。Selection、Trim、Blade | `Tool` |
| ズームバー | Timeline の下端の横のバー。全体の長さの上に見えている範囲を示し、中のドラッグで動かし、両端のドラッグで拡大縮小する | `zoombar.rs` |
| 全体表示 | コンポジションの全体を Timeline の幅に収めた表示（Full Extent Zoom）。Shift+Z で元の倍率と行き来する | `TimeView::fit` |
| スナップの表示 | スナップしたときだけ出す、ガイド線と上下の三角と、吸い付いた先の強調 | `PaintState::guide` |
| ガイド線（スナップの） | 吸い付いたときだけ出す縦の線。吸い付いていないドラッグには出さない | `PaintState::guide` |
| ドラッグ中のツールチップ | ドラッグ中にポインターの横に出す、動かした量（フレームか時刻） | — |
| 再生の操作のバー | Program と Source の下の、時刻、再生とマークのボタン、ジョグバーを並べた横長の領域 | `transport.rs` |
| ジョグバー | 再生の操作のバーの、コンポジション（Source では素材）の全体を 1 本で表すバー。クリックとドラッグで再生位置を動かす | `transport.rs` |
| ステータスバー | サーフェスの下端の 1 行。左にポインターの下でできる操作、右にスナップの入/切と選んだツールを出す（隠した行の数は見出しの列の上） | `hint.rs` |
| マーカー（キーフレームの） | キーフレームの時刻に出すひし形。Inspector のパラメータの行と、Timeline の帯の下端（そのレイヤーの全部のパラメータの分）に出す | `inspector.css`、`keymarks.rs` |
| キーフレームの行 | レイヤーの行の下に開く、キーフレームのあるパラメータごとの行 | `keymarks.rs` |
| キーフレームの欄（Inspector の） | Inspector のパラメータの行の右の、選んだレイヤーの範囲の時間の欄 | `KeyframeStrip.tsx` |
| 区画（Inspector の） | Inspector のパラメータのまとまり（Transform、Opacity など）。見出しの行で畳める | `mm-insp-section` |
| Clip（画面の文言） | 画面でシーケンスのカットと素材を指す英語（Premiere と Resolve の語）。コードと設計書はカットと素材のまま | — |

## 置き換えた語

### UI の分かりやすさ

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| トラック、段 | Timeline の 1 行。トラックは Mixer のトラック（音を持てるレイヤー）と紛れ、段は 1 字で意味が定まらない | レイヤーの行 |
| トラックの見出し、段の見出し | レイヤーの行の左端 | レイヤーの見出し |
| 段の高さ | レイヤーの行の 3 つの高さ | 行の高さ |
| キーフレームの段 | レイヤーの行の下に開く、パラメータごとの行 | キーフレームの行 |
| 目、鍵 | レイヤーの見出しのボタン | 有効のボタン、ロックのボタン |
| 印 | 帯の下端のキーフレームのひし形 / Shy を付けたこと / スナップしたときのガイド線と三角 / トランジション | マーカー（キーフレームの）/ フラグ / スナップの表示 / 箱 |
| 札（量の） | ドラッグ中にポインターの横に出す、動かした量 | ドラッグ中のツールチップ |
| 案内の行 | サーフェスの下端の 1 行 | ステータスバー |
| 再生の操作の列 | Program と Source の下の横長の領域 | 再生の操作のバー |
| 窓 | Tauri と Win32 の window | ウィンドウ |
| 画 | 帯の先頭の 1 枚 / 素材から間隔を置いて作る小さな画像 / 終わりの条件で撮るもの / カーソルの絵 | サムネイル / 縮小画像 / スクリーンショット / 画像 |
| 組 | Inspector のパラメータのまとまり / PR のまとまり / ツールバーのボタンのまとまり / コマンドの ID の前半 | 区画 / 分類 / グループ / 分類 |
| 道具 | Win32 のツールチップに登録する矩形（tool） | ツールチップの対象 |
| 境目 | 画面の領域の間 / トラックの見出しの間 | 境界 |
| 写す | ep03 を作業用のフォルダーへ / キーフレームの時刻 | コピーする / 変換する |
| 版 | Adobe の古いユーザーガイド / 画面の言語 / マニュアルの発行の月 | バージョン / 英語の UI / （月）のもの |
| ◀ ◆ ▶ | Inspector のパラメータの、前のキーへ・打つ/外す・次のキーへ | キーフレームナビゲーター |
| NLE | 他の動画編集ソフト | 編集ソフト |
| プレビュー | 中央の列の見出し。プレビュー動画と紛れる | 再生の操作のバー / Diagnostics |
| 全体を収める | Timeline の倍率 | 全体表示 |

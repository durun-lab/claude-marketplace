## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| コマンドの表（UI の） | 画面の操作の一覧。ID、英語の名前、キー、説明、メニューの場所、持ち主（Rust か WebView のパネル）、押せるかを持つ。メニュー、ツールチップ、Keyboard Shortcuts の窓、案内の行、Tasks が同じ表を読む。データの変更は操作（`Op`）のまま | `commands.rs`、`run_command` |
| 割り付け（窓の） | 窓をサーフェスと WebView の矩形に分けたもの | `split_rects`、`win/layout.rs` |
| 仕切り | 割り付けの境目（サーフェスと WebView の境、Program と Timeline の境）。ドラッグで動かす | `win/layout.rs` |
| Diagnostics | 開発の情報（GPU、実装、通知の遅れ、時計、レイヤーの生の一覧）を出すパネル | `ui/panels/diagnostics` |
| Keyboard Shortcuts の窓 | `?` で開く別の窓。コマンドを名前とキーで探して実行する | `ui/shortcuts` |

## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 段（Timeline の） | レイヤー 1 本ぶんの横長の領域。帯と段の見出しを持ち、上が前のレイヤー | `row_top` |
| 段の見出し | 段の左端の、種類の色と略号、名前、目、鍵、M と S、▸ を並べた所。ほかのソフトのトラックの見出し（track header）にあたる | `header.rs` |
| 段の高さ | 段の 3 つの高さ（S 18、M 28、L 56 論理ピクセル）。高さに応じて、帯に名前、先頭の画、フィルムストリップ、波形を出し分ける | `RowHeight` |
| 表示の状態（Timeline の） | ズーム、スクロール、段の高さ、Shy、スナップの入/切。プロジェクトのデータに入れず、取り消しの列と `versions/` にも入らない | `.mm/view.json` |
| Shy | Timeline の表示からだけ外すレイヤーの印（AE の Shy）。描画と書き出しは変わらない | 表示の状態 |
| ツールバー（Timeline の） | Timeline の上端の段。取り消し、ツール、編集、スナップ、ズームのボタンを並べる | `toolbar.rs` |
| ツール（Timeline の） | 帯の中と端のドラッグが何をするかを決める状態。Selection、Trim、Blade | `Tool` |
| ズームバー | Timeline の下端の横のバー。全体の長さの上に見えている範囲を示し、中のドラッグで動かし、両端のドラッグで拡大縮小する | `zoombar.rs` |
| 全体表示 | コンポジションの全体を Timeline の幅に収めた表示（Full Extent Zoom）。Shift+Z で元の倍率と行き来する | `TimeView::fit` |
| 吸い付きの印 | スナップしたときだけ出す、ガイド線と上下の三角と、吸い付いた先の強調 | `PaintState::guide` |
| ガイド線（スナップの） | 吸い付いたときだけ出す縦の線。吸い付いていないドラッグには出さない | `PaintState::guide` |
| 量の札 | ドラッグ中にポインターの横に出す、動かした量（フレームか時刻） | — |
| 再生の操作の列 | Program と Source の下の、時刻、再生とマークのボタン、ジョグバーの列 | `transport.rs` |
| ジョグバー | 再生の操作の列の、コンポジション（Source では素材）の全体を 1 本で表すバー。クリックとドラッグで再生位置を動かす | `transport.rs` |
| 案内の行 | サーフェスの下端の 1 行。左にポインターの下でできる操作、右にスナップの入/切と選んだツールを出す（隠した段の数は見出しの列の上） | `hint.rs` |
| キーフレームの印（帯の） | 帯の下端に並ぶ、そのレイヤーの全部のパラメータのキーフレームの時刻のひし形 | `keymarks.rs` |
| キーフレームの段 | レイヤーの段の下に開く、キーフレームのあるパラメータごとの段 | `keymarks.rs` |
| キーフレームの欄（Inspector の） | Inspector のパラメータの行の右の、選んだレイヤーの範囲の時間の欄 | `KeyframeStrip.tsx` |
| Clip（画面の文言） | 画面でシーケンスのカットと素材を指す英語（Premiere と Resolve の語）。コードと設計書はカットと素材のまま | — |

## 置き換えた語

### UI の分かりやすさ

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| トラック | Timeline の 1 行。Mixer のトラック（音を持てるレイヤー）と紛れる | 段 |
| トラックの見出し | 段の左端 | 段の見出し |
| プレビュー | 中央の列の見出し。プレビュー動画と紛れる | 再生の操作の列 / Diagnostics |
| 全体を収める | Timeline の倍率 | 全体表示 |

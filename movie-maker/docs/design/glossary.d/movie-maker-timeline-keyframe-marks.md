## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| マーカー（帯の） | Timeline の帯の下端に出す、そのレイヤーのパラメータ（再フレーミングを除く）のキーフレームの時刻の印。一辺 9 論理ピクセルのひし形で、近いものはまとめる。押すとレイヤーを選び、再生位置をその時刻へ動かす。文中では「帯のマーカー」。Inspector のマーカー（キーフレームの）とひし形（キーフレームの欄の）とは別 | `keymarks`、`BarMark`、`Hit::BarMark`、`Depth::BarMark`、`MARK_PX` |
| 縦線（帯のマーカーの） | 帯のマーカーをひし形の代わりに描く、幅 2 論理ピクセルの縦の線。Small の行（下端から 4 論理ピクセル）と、ひし形が行の領域からはみ出す位置（下端から 7 論理ピクセル）で使う。切っても形が変わらないので、行の領域で切る | `keymarks::is_line`、`line_rect` |
| まとめる（帯のマーカーを） | 先頭のキーフレームから順に、直前のマーカーとの差が 6 論理ピクセルより小さいキーフレームを、そのマーカーに含めること。先頭から数えるので、横に動かしてもマーカーの位置は変わらない | `MERGE_PX`、`keymarks::marks` |
| キーフレームの時刻（レイヤーの） | レイヤーのコンポジションの時刻のパラメータ（`shiftLayer` が動かすもの）のキーフレームの時刻を、前から順に重複なしで並べたもの。帯のマーカーが使う | `Layer::keyframe_times`、`Layer::comp_time_params`、`Item::keyframes` |
| accent（サーフェスの） | ポインターが指している操作の対象の色（テーマの `accent`）。ホバーした帯のマーカーのひし形の中に使い、Inspector で選んだキーフレームと同じ色 | `Palette::accent` |

## 置き換えた語

### UI の分かりやすさ（K1、帯のマーカー）

| 元の語 | 文脈 | 正式な用語 |
|---|---|---|
| キーフレームのマーカー（Timeline の帯の） | 帯の下端のキーフレームの印。用語集のマーカー（キーフレームの）は Inspector のパラメータの名前の横のひし形で、紛れる | マーカー（帯の）、文中では帯のマーカー |
| `Hit::Key`、`key`（`Item::keyframes` の添字） | 帯のマーカーの当たり。Key はキーボードのキー（`keys.rs`、K2 の `[` と `]`）と紛れる | `Hit::BarMark`、`keyframe` |
| `Mark`、`Depth::Mark` | 帯のマーカー 1 つと、その重ね順。Mark は Source の In と Out の印（Mark In、Mark Out）と、コンポジションのマーカーと紛れる | `BarMark`、`Depth::BarMark` |
| `tick`（`is_tick`、`tick_rect`、`TICK_W`、`TICK_H`） | ひし形の代わりに描く縦の線。tick は目盛り（`ruler::ticks`、`palette::TICK`）と紛れる | 縦線（帯のマーカーの）（`is_line`、`line_rect`、`LINE_W`） |
| 種類（ひし形と縦線の） | 帯のマーカーの見た目の違い。レイヤーの種類（`ItemKind`）と紛れる | 形 |
| 外縁、塗り（`FILL_PX`） | 帯のマーカーのひし形の、暗い外側と明るい内側。塗りは Quad の形のテストの前景と紛れる | ひし形の縁、ひし形の中（`INNER_PX`） |
| `lit` | ポインターが乗っている帯のマーカー | `hovered` |
| `reach` | 帯のマーカーの中心から、ひし形の左右の端まで | `half` |
| `anchor`（まとめる所の） | 直前の帯のマーカーの x。レイヤーのアンカー（`transform.anchor`）と紛れる | `last_x` |
| `seek_to` | 時刻を、再生位置を動かすときの時刻にそろえる関数。値を返すだけなのに、動かす操作に読める | `seek_time` |
| フレームの境目（に丸める） | 再生位置を動かすときの時刻のそろえ方 | いちばん近いフレームの先頭にそろえる |
| 読む向き（`comp_time_params_ref`） | `comp_time_params` の、書き換えない参照の一覧 | `Layer::comp_time_params`（書き換える方は `Layer::comp_time_params_mut`） |
| 名前を置く所（Large の帯の） | Medium の帯も名前を上の部分に置くので、Large だけの語でなくなった | 名前を置く所（帯の） |

## 構造と開発

| 用語 | 定義 | 識別子 |
|---|---|---|
| 再生テスト | アプリを実際のウィンドウで開き、要求の秒数だけ再生して数とスクリーンショットを残し、入力、Inspector、Timeline の編集の工程を通して、結果の JSON を書いて終わるテスト。適用した編集はセーブポイントまで戻す | `--play-test`、`win/verify.rs` |
| 工程（再生テストの） | 再生テストを分けた部分（再生、入力、Inspector、Timeline の編集）。1 つずつ別のスレッドで実行し、上限の時間を過ぎたら時間切れにする。書き出しの工程とは別 | `verify_stage::run`、`failed_stages` |
| 時間切れ（工程の） | 工程が上限の時間までに結果を返さないこと。その工程のスレッドは次の待ちでスタックを巻き戻して止まり、後の工程は実行しない | `StageError::TimedOut`、`checkpoint` |
| セーブポイント（再生テストの） | 再生テストの前の取り消しのスタックの位置とプロジェクトのデータ。テストの後、この位置まで取り消し（取り消しすぎた分はやり直し）、位置より前の履歴には触らない | `Savepoint`、`restore` |

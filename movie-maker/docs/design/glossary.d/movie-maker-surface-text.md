## 再生と Timeline

| 用語 | 定義 | 識別子 |
|---|---|---|
| 帯の名前 | Timeline の帯の中に出す文字。レイヤーにもカットにも名前の欄が無いので、素材の名前（撮影素材のファイル名、文字の最初の行など）を出し、種類は帯の色に任せる。素材の名前が無いもの（単色）は種類の名前 | `Item::label`、`CutBar::label`、`mm-ui-wgpu/src/names.rs` |
| 切り詰め | 矩形に入らない文字を、書記素クラスタの境の入る所までにして「…」を付けること。1 字と「…」も入らなければ出さない | `fit`、`Fit`、`ELLIPSIS` |
| 切り詰めの位置 | 切り詰めで切ってよい位置（書記素クラスタの終わり。空白の後ろは除く）の、左端からの距離 | `TextMeasure::stops` |
| 矩形に置く（文字を） | 文字を矩形の中に 1 行で置くこと。縦は中央、横は余白を空けて揃え方に従い、入らなければ左に揃えて切り詰め、矩形の外には描かない | `place`、`Align`、`TextStyle`、`Label::clip` |
| 文字の描画（サーフェスの） | サーフェスの文字をシェーピングしてキャッシュし、glyphon で描く部品。置き場所と色が前のフレームと同じなら頂点を作り直さない | `TextLayer`、`Shaper`、`TextStats` |

## 文字

| 用語 | 定義 | 識別子 |
|---|---|---|
| フォールバックのフォント（サーフェスの UI の） | テーマのフォントに無い字をシェーピングするフォント。日本語の字（と全角の記号だけの語）は Yu Gothic UI、Meiryo の順。絵文字と記号は cosmic-text の Windows の既定（Segoe UI Emoji、Segoe UI Symbol） | `UiFallback`、`JAPANESE`、`COMMON` |
| 書記素クラスタ | 読み手が 1 字と見なす字のまとまり（基底の字と結合する記号など）。シェーピングでは `start` が同じグリフの並び | `stops_of` |
| 省略記号 | 切り詰めた文字列の後ろに付ける「…」（U+2026） | `ELLIPSIS` |
| 行の矩形 | 1 行の字を置く矩形。高さは字の大きさの 1.25 倍を整数の論理ピクセルに切り上げた値 | `line_height`、`Label` |

## モバイル版

| 用語 | 定義 | 識別子 |
|---|---|---|
| モバイル版 | 自宅の PC の `mm-serve` が配り、出先のスマホのブラウザーで開く PWA。描画もデータも持たず、見る、コメントを書く、Story の操作、提案を決めるを受け持つ | `ui/mobile/` |
| 人の待ち受け | `mm-serve` の 2 つ目の待ち受け。127.0.0.1 の決まったポートで待ち、`tailscale serve` が tailnet に出す。来た操作は全部人の操作経路 | `Entry::Mobile`、`/m` |
| Claude の待ち受け | `mm-serve` の今の待ち受け。空きポートとトークンで、CLI と MCP が使う | `Server`、`/mcp` |
| 端末の登録 | PC のアプリが出す 5 分だけの登録の符号を、モバイルが送って端末の資格を受け取ること | `POST /m/pair` |
| 端末の資格 | 登録した端末が持つ 32 バイトの乱数。クッキーで送り、PC はハッシュだけを持つ | `devices.json` |
| 配信の区間 | HLS で送る 4 秒の映像。区間に掛かるノードのキャッシュのキーと画質から作るキーで覚え、編集で変わらない区間は作り直さない | `mm-stream`、`cache/mobile/` |
